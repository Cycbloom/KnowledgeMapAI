# KnowledgeMap 桌面应用使用指南

## 1. 安装与启动

### 1.1 Windows 安装
1. **下载安装包**：从官方网站或 GitHub 发布页面下载 Windows 安装包（`.exe` 文件）
2. **运行安装程序**：双击安装包，按照向导完成安装
3. **启动应用**：安装完成后，从开始菜单或桌面快捷方式启动应用

### 1.2 Windows 便携版使用
1. **下载便携版**：从官方网站或 GitHub 发布页面下载 Windows 便携版（`.zip` 文件）
2. **解压文件**：将压缩包解压到任意文件夹
3. **运行应用**：双击 `KnowledgeMap.exe` 启动应用

### 1.3 macOS 安装
1. **下载 DMG 镜像**：从官方网站或 GitHub 发布页面下载 macOS 安装包（`.dmg` 文件）
2. **安装应用**：打开 DMG 镜像，将 KnowledgeMap 拖拽到应用文件夹
3. **启动应用**：从应用文件夹启动 KnowledgeMap

## 2. 首次使用设置

### 2.1 账户创建
1. **启动应用**：首次启动应用时，会自动打开注册页面
2. **填写注册信息**：输入邮箱、用户名和密码
3. **完成注册**：点击「注册」按钮完成账户创建
4. **登录应用**：使用创建的账户登录

### 2.2 数据导入（可选）
1. **进入设置页面**：点击左侧菜单的「设置」
2. **选择数据导入**：在设置页面中找到「数据导入」选项
3. **选择导入源**：选择从 Supabase 云端导入数据
4. **输入 Supabase 凭据**：输入您的 Supabase 项目 URL 和 API 密钥
5. **开始导入**：点击「开始导入」按钮，等待导入完成

## 3. 核心功能使用

### 3.1 知识图谱创建与编辑
1. **创建图谱**：点击左侧菜单的「知识图谱」，然后点击「创建新图谱」
2. **编辑图谱**：
   - 点击节点可以编辑内容
   - 拖拽节点可以调整位置
   - 点击「添加节点」可以创建新节点
   - 点击「添加连接」可以创建节点间的连接
3. **保存图谱**：点击「保存」按钮保存图谱

### 3.2 学习路径管理
1. **进入学习路径**：点击左侧菜单的「学习路径」
2. **创建路径**：点击「创建新路径」
3. **编辑路径**：
   - 添加学习节点
   - 设置学习顺序
   - 设置学习时间
4. **跟踪进度**：在学习过程中标记完成状态

### 3.3 任务调度
1. **进入任务**：点击左侧菜单的「任务」
2. **创建任务**：点击「创建新任务」
3. **设置任务**：
   - 输入任务名称和描述
   - 设置截止日期
   - 分配优先级
4. **管理任务**：标记任务完成状态，查看任务列表

### 3.4 AI 功能
1. **进入 AI 助手**：点击左侧菜单的「AI 助手」
2. **配置 API Key**：在设置页面中输入您的 AI 服务 API Key
3. **使用 AI 功能**：
   - 生成知识图谱
   - 总结学习内容
   - 回答问题
   - 提供学习建议

### 3.5 数据导入导出
1. **进入设置**：点击左侧菜单的「设置」
2. **选择数据管理**：找到「数据管理」选项
3. **导出数据**：点击「导出数据」按钮，选择导出格式（JSON 或 CSV）
4. **导入数据**：点击「导入数据」按钮，选择要导入的文件

### 3.6 数据备份恢复
1. **进入设置**：点击左侧菜单的「设置」
2. **选择备份恢复**：找到「备份恢复」选项
3. **创建备份**：点击「创建备份」按钮，系统会自动创建数据库备份
4. **恢复备份**：点击「恢复备份」按钮，选择要恢复的备份文件

## 4. 数据同步功能

### 4.1 同步设置
1. **进入同步设置**：点击左侧菜单的「同步设置」
2. **选择同步模式**：
   - **局域网同步**：适合同一网络内的设备
   - **云同步**：适合远程设备（需要配置云存储）
3. **配置同步选项**：
   - 自动同步：设置同步频率
   - 手动同步：需要时手动触发

### 4.2 局域网同步
#### 4.2.1 桌面端设置
1. **确保设备在同一网络**：确保电脑和手机连接到同一 Wi-Fi 网络
2. **开启同步服务**：在同步设置页面中开启「局域网同步服务」
3. **查看设备二维码**：系统会生成一个包含设备信息的二维码

#### 4.2.2 移动端设置
1. **打开移动端 PWA**：在手机浏览器中访问桌面端显示的本地服务器地址
2. **扫描二维码**：使用手机摄像头扫描桌面端显示的二维码
3. **完成配对**：确认设备信息，完成配对
4. **开始同步**：点击「开始同步」按钮，等待同步完成

### 4.3 同步状态查看
1. **进入同步设置**：点击左侧菜单的「同步设置」
2. **查看同步状态**：页面会显示当前同步状态，包括：
   - 上次同步时间
   - 同步设备列表
   - 同步进度
   - 同步错误（如有）

### 4.4 冲突处理
1. **冲突检测**：当同一数据在多设备被修改时，系统会检测到冲突
2. **冲突解决**：
   - **自动合并**：系统会尝试自动合并可兼容的更改
   - **手动选择**：对于无法自动合并的冲突，系统会提示您选择保留哪个版本
   - **自定义合并**：您可以手动编辑合并结果

## 5. 离线使用

### 5.1 离线模式
1. **无网络环境**：当应用检测到无网络连接时，会自动切换到离线模式
2. **离线功能**：
   - 所有核心功能（知识图谱、学习路径、任务等）正常工作
   - AI 功能会显示离线提示
   - 数据会保存在本地数据库

### 5.2 网络恢复后
1. **自动同步**：当网络恢复后，应用会自动尝试同步离线期间的更改
2. **同步状态**：您可以在同步设置页面查看同步结果

## 6. 应用管理

### 6.1 自动更新
1. **检查更新**：应用启动时会自动检查更新
2. **安装更新**：当有新版本时，系统会提示您安装
3. **手动检查**：在设置页面中点击「检查更新」按钮

### 6.2 崩溃报告
1. **自动上报**：当应用崩溃时，系统会自动收集崩溃信息并上报
2. **隐私设置**：您可以在设置页面中选择是否允许崩溃报告

### 6.3 性能优化
1. **启动速度**：应用启动时间控制在 5 秒以内
2. **内存使用**：优化内存使用，确保应用运行流畅
3. **存储管理**：定期清理缓存和临时文件

## 7. 常见问题与解决方案

### 7.1 安装问题
- **安装失败**：尝试以管理员身份运行安装程序
- **权限不足**：确保您有足够的权限安装应用
- **防病毒软件拦截**：暂时禁用防病毒软件后重试

### 7.2 同步问题
- **设备未发现**：确保设备在同一网络，检查防火墙设置
- **同步失败**：检查网络连接，尝试重新配对
- **冲突频繁**：尽量避免在多设备同时编辑同一数据

### 7.3 性能问题
- **启动缓慢**：检查系统资源使用情况，关闭不必要的应用
- **运行卡顿**：尝试清理缓存，重启应用
- **内存占用高**：关闭不需要的标签页和功能

### 7.4 数据问题
- **数据丢失**：定期创建备份，使用数据导出功能
- **导入失败**：检查文件格式是否正确，确保文件不损坏
- **数据库错误**：尝试恢复备份，或重新安装应用
