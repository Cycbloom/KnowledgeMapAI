# 3D 知识星球功能实现计划

## 功能概述

将知识图谱以 3D 星球/星系的形式展示，节点变成星球，连线变成轨道或光线，提供沉浸式的知识探索体验。

## 技术方案

### 依赖
- Three.js (已有 ^0.160.0)
- @react-three/fiber (需新增) - React Three.js 渲染器
- @react-three/drei (需新增) - Three.js 常用工具集

### 核心功能

#### 1. 3D 场景渲染
- 节点渲染为发光星球，大小根据重要性/子节点数决定
- 连线渲染为发光曲线或粒子流
- 星空背景 + 动态粒子效果

#### 2. 交互功能
- OrbitControls: 旋转、缩放、平移
- 点击星球: 选中节点，显示详情面板
- 悬停效果: 星球高亮 + 显示标签
- 双击: 聚焦到该节点为中心

#### 3. 视觉效果
- 节点发光效果 (Bloom)
- 不同层级/状态使用不同颜色
- 连线动画 (粒子流动)
- 星球自转动画

#### 4. 布局算法
- 3D 力导向布局
- 核心节点在中心，子节点围绕分布
- 支持按层级分层 (类似太阳系)

## 实现步骤

### 第一阶段：基础框架
1. 安装 @react-three/fiber 和 @react-three/drei
2. 创建 PlanetView 基础组件
3. 实现 3D 力导向布局算法
4. 渲染基础星球和连线

### 第二阶段：交互功能
1. 添加 OrbitControls
2. 实现节点点击选中
3. 实现悬停高亮效果
4. 添加节点标签显示

### 第三阶段：视觉效果
1. 添加 Bloom 后处理效果
2. 实现星球发光材质
3. 添加星空背景
4. 连线粒子动画

### 第四阶段：集成
1. 添加 'planet' 到 GraphViewMode 类型
2. 更新 ViewModeSelector
3. 在 GraphEditor 中集成

## 视觉设计

### 星球样式
| 节点类型 | 颜色 | 大小 |
|---------|------|------|
| 根节点 | 金色发光 | 最大 |
| 核心节点 | 橙色 | 大 |
| 普通节点 | 蓝色 | 中 |
| 叶子节点 | 青色 | 小 |

### 连线样式
- 渐变色发光曲线
- 可选粒子流动动画
- 粗细根据关系强度

### 背景
- 深色星空
- 随机分布的星星粒子
- 可选星云效果
