# Dashboard 模块测试验证计划

## 目标

运行 Dashboard 模块测试，验证之前启用的 16 个测试是否正常工作。

## 实施步骤

### 步骤 1: 运行 Dashboard 模块测试
- 执行 `npm run test:dashboard` 命令
- 验证只运行 dashboard.spec.ts 测试文件

### 步骤 2: 分析测试结果
- 检查测试是否成功执行
- 记录通过的测试数量
- 记录失败的测试（如有）
- 生成测试报告摘要

### 步骤 3: 修复失败的测试（如有）
- 分析失败原因
- 修复测试代码或标记为跳过

## 预期结果

- 测试命令执行成功
- 只运行 Dashboard 相关测试
- 测试报告显示各测试用例的执行结果

## 注意事项

- 需要确保本地 Supabase 服务正常运行
- 测试用户账号 `test@example.com` / `test123456` 需要存在
- Dashboard 测试需要图谱数据
