# 测试失败分析与修复计划

## 问题分析

### 1. 创建图谱测试失败

**根本原因**：应用有主题相似度检测功能，当新图谱与现有图谱相似度高时会禁用创建按钮。

**错误上下文**：
```
- 主题重复
- 与现有图谱「测试图谱_1772108363174」相似度为 96.6%
- button "立即创建" [disabled]
```

**修复方案**：
- 测试代码：使用更独特的图谱名称（添加更多随机字符）
- 或跳过此测试（因为这是业务逻辑限制，不是 bug）

### 2. 收藏功能测试失败

**根本原因**：创建图谱过程耗时较长，测试在创建完成前就尝试收藏操作。

**错误上下文**：
```
- button "创建中..." [disabled]
```

**修复方案**：
- 增加等待时间
- 使用已有的图谱进行收藏测试，而不是每次都创建新图谱

### 3. DashboardPage.ts 选择器问题

**问题**：
- `openCreateGraphModal()` 期望有模板选择器和跳过按钮，- `isDarkMode()` 使用错误的选择器

**修复方案**：
- 更新 `openCreateGraphModal()` 方法
- 更新 `isDarkMode()` 方法

## 实施步骤

### 步骤 1: 修复 DashboardPage.ts
- 更新 `openCreateGraphModal()` 方法
- 更新 `isDarkMode()` 方法

### 步骤 2: 修复测试代码
- 更新创建图谱测试，- 更新收藏功能测试

### 步骤 3: 运行测试验证
- 运行 `npm run test:dashboard` 验证修复效果
