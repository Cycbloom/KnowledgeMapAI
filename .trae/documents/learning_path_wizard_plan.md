# 学习路径 AI 规划优化计划

## 目标

将学习路径的 AI 规划功能从"用户自由输入"改为"AI 引导问答"形式，提升用户体验。

## 当前问题

### 学习目标输入
- 用户需要自己思考并输入学习目标
- 可能不知道如何描述目标
- 输入内容可能不够清晰

### 知识背景输入
- 用户需要自己描述知识背景
- 可能遗漏重要信息
- AI 难以准确评估用户水平

## 技术实现

### 1. 后端 API

#### 新增端点：`POST /learning-path/questions`

根据图谱主题生成引导问题：

```typescript
interface LearningPathQuestionsRequest {
  graph_id: string;
}

interface LearningPathQuestionsResponse {
  graphTitle: string;
  suggestedGoals: string[];        // AI 推荐的学习目标（3-4个）
  prerequisiteQuestions: {         // 前置知识问题
    topic: string;                 // 知识点名称
    description?: string;          // 简短描述
    options: string[];             // 选项：不了解/了解一点/比较熟悉/非常熟悉
  }[];
}
```

### 2. 前端组件

#### 新增组件：`LearningPathWizard.tsx`

分步引导用户完成学习路径规划：

- **Step 1**: 选择学习目标（AI 推荐选项 + 自定义输入）
- **Step 2**: 评估前置知识（AI 生成的知识问题）
- **Step 3**: 学习偏好设置（时间、风格）
- **Step 4**: 生成结果

### 3. 数据库

#### 新增 Prompt 模板：`learning_path_questions`

用于生成引导问题的 AI prompt。
