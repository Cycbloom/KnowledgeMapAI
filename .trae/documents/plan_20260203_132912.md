# 项目全面分析与功能迭代路线图

基于对代码库的深度分析，以下是项目现状梳理、问题识别及未来的功能迭代规划。

## 1. 项目现状深度分析

### 1.1 核心架构与技术栈
项目采用现代化的 **Monorepo 风格全栈架构**：
- **前端**: React 18 + TypeScript + Vite + Zustand (状态) + TailwindCSS (UI)。核心特色是基于 `react-three-fiber` 的 3D 图谱可视化。
- **后端**: Node.js + Express + TypeScript。采用分层架构 (Routes/Services/Utils)。
- **数据层**: Supabase (PostgreSQL + pgvector) 实现数据持久化与向量检索。
- **AI/异步**: 多供应商 AI 接入 (DeepSeek/Aliyun/Volcengine) + BullMQ/Redis 任务队列处理耗时任务。

### 1.2 已实现核心功能
1.  **3D 知识图谱**: 节点的增删改查、可视化展示、层级渲染 (LOD)、力导向布局。
2.  **AI 辅助生成**: 文本转图谱、图谱扩展、概念解释、相关节点推荐 (RAG)。
3.  **学习系统**: 基于 FSRS 算法的间隔重复复习 (Flashcards)、学习模式 (Split View)。
4.  **系统基础**: 完整的认证流程、异步任务管理、移动端适配模式、Markdown 导出。

### 1.3 技术债务与改进空间
| 类别 | 问题描述 | 影响评估 |
| :--- | :--- | :--- |
| **测试缺失** | 仅有少量后端测试，前端组件与 E2E 测试几乎空白 | 长期维护风险高，重构易引入 Bug |
| **性能瓶颈** | 大数据量 (>1000节点) 下 3D 渲染与物理模拟可能掉帧 | 限制了重度用户的使用体验 |
| **协作能力** | 当前仅支持单人模式，缺乏实时协作或分享机制 | 限制了团队场景或社交传播 |
| **离线支持** | 强依赖网络与后端 API，无离线缓存或 PWA 支持 | 网络不稳定时不可用 |

## 2. 功能扩展清单 (Feature Extension List)

### 2.1 P0 - 核心体验优化 (Immediate Value)
- **功能点**: **3D 渲染性能分级 (Performance Tiering)**
    - *描述*: 引入 InstancedMesh，优化 LOD 策略，根据设备性能自动降级画质。
    - *价值*: 确保低端设备和移动端流畅运行。
    - *可行性*: 高 (Three.js 生态成熟)。
- **功能点**: **全链路错误边界与恢复 (Global Error Boundary)**
    - *描述*: 完善前端 Error Boundary 和后端重试机制 (Retries)，特别是针对 AI 超时。
    - *价值*: 提升系统稳定性，减少白屏。
    - *可行性*: 中 (需梳理异常流)。

### 2.2 P1 - 功能深度增强 (Core Growth)
- **功能点**: **智能文档导入 (Smart Doc Import)**
    - *描述*: 支持 PDF/Notion/Web 链接直接解析为图谱 (RAG 预处理)。
    - *价值*: 极大降低用户构建图谱的门槛。
    - *可行性*: 中 (需引入解析库如 pdf.js/cheerio + 现有 AI 提取能力)。
- **功能点**: **协作与分享 (Collaboration)**
    - *描述*: 生成只读分享链接，或简单的多人实时编辑 (WebSocket)。
    - *价值*: 增加产品的传播属性。
    - *可行性*: 复杂 (需改造状态同步逻辑)。

### 2.3 P2 - 长期生态建设 (Long-term)
- **功能点**: **插件系统 (Plugin Architecture)**
    - *描述*: 允许第三方开发图谱渲染特效或 AI Prompt 模板。
    - *价值*: 建立社区生态。
    - *可行性*: 复杂 (需设计沙箱机制)。

## 3. 产品功能迭代路线图 (Roadmap)

### 🚀 Phase 1: 稳健性与基础体验 (v1.1 - Next 2 Weeks)
**目标**: 修复技术债务，确保现有功能“如丝般顺滑”。
1.  **测试覆盖**: 引入 Jest/Vitest + React Testing Library，完成核心组件 (GraphEditor) 测试。
2.  **性能优化**: 实现更激进的各种层级 LOD (Level of Detail)，优化 React 渲染周期。
3.  **UI/UX 细节**: 优化移动端手势交互，统一 Loading 状态与错误提示。

### ⭐ Phase 2: 内容输入与输出增强 (v1.2 - Next 1 Month)
**目标**: 让知识“进得来，出得去”。
1.  **多源导入**: 实现 PDF/Markdown 文件拖拽生成图谱。
2.  **富媒体导出**: 导出包含图谱截图、详细笔记的高质量 PDF 报告。
3.  **AI 对话增强**: 支持引用图谱特定节点进行多轮对话 (Context-aware Chat)。

### 🌐 Phase 3: 互联与协作 (v2.0 - Next Quarter)
**目标**: 从“个人工具”迈向“协作平台”。
1.  **云端同步优化**: 引入 WebSocket 实现更实时的状态同步。
2.  **图谱分享广场**: 允许用户公开发布自己的知识图谱。
3.  **PWA 支持**: 实现离线访问与本地缓存。

---

**下一步建议 (Next Steps):**
建议首先从 **Phase 1** 启动，重点建立**前端测试框架**和**3D性能优化**，为后续复杂功能打好地基。
