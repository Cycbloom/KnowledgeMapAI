# Phase 2: Smart Document Import & Rich Export

Based on the analysis, the basic plumbing for PDF import exists but can be improved. The current workflow is split (frontend vs backend parsing). I will unify and enhance this experience.

## 1. Smart Document Import (Enhancement)
The goal is to provide a seamless "Drag & Drop" experience for any document type, with better feedback and error handling.

### Frontend: `TextToGraphModal.tsx`
- **Unified Upload Zone**: Improve the UI to be a clear drag-and-drop zone.
- **Smart Routing**:
    - **PDF**: Continue sending to `/api/ai/document-to-graph`.
    - **Markdown/Text**: Keep frontend parsing but improve preview. Show extracted text to user *before* sending to AI, allowing them to edit/refine.
    - **URL Import (New)**: Add a tab to input a URL (e.g., a blog post), scrape content (backend), and generate graph.

### Backend: `api/routes/ai.ts` & `api/utils/scraper.ts` (New)
- **Web Scraping**: Create a simple utility to fetch text from a URL (using `cheerio` or `puppeteer` if available, or just `fetch` + DOM parser).
- **Endpoint**: Add `/api/ai/url-to-graph` endpoint.

## 2. Rich Media Export (New Feature)
Currently, export is limited to raw data or basic PDF. Users want "Reports".

### Frontend: `GraphEditor.tsx` & `ExportDialog.tsx` (New)
- Create a dedicated `ExportDialog` component replacing the simple menu.
- **Preview**: Show what the report will look like.
- **Options**:
    - Include Screenshot (captured from Canvas).
    - Include Node Details (content).
    - Layout style (Compact vs Detailed).

### Backend: `api/routes/data.ts`
- Enhance `/export/pdf` to accept a `screenshot` (base64) and `options`.
- Use `pdfkit` to layout a nice report:
    - Cover Page (Title, Date, Screenshot).
    - Table of Contents.
    - Node Details (iterate through nodes).

## 3. Implementation Steps

1.  **Refactor `TextToGraphModal`**: Improve UI for file upload and add URL tab.
2.  **Backend Web Scraper**: Implement URL text extraction.
3.  **Rich Export UI**: Create `ExportDialog`.
4.  **Backend PDF Generation**: Upgrade `api/utils/pdfGenerator.ts` (or similar) to support rich reports.

I will start with **Step 1 & 2: Smart Import enhancements**.
