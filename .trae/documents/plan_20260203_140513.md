# Phase 3: PWA & Public Sharing

Since PWA support and Public Sharing are currently missing, I will implement them to enhance accessibility and collaboration.

## 1. PWA Implementation (Offline Access)
- **Install**: `vite-plugin-pwa`.
- **Config**: Update `vite.config.ts` to generate `manifest.json` and service worker.
    - **Manifest**: Name, Short Name, Icons, Theme Color.
    - **Service Worker**: Cache strategy for assets (StaleWhileRevalidate) and API (NetworkFirst).
- **UI**: Add an "Install App" button in the Sidebar/Header if the `beforeinstallprompt` event is detected.

## 2. Public Sharing (Collaboration)
- **Database**: Add `is_public` (boolean, default false) to `knowledge_graphs` table.
- **Backend API (`api/routes/graphs.ts`)**:
    - Update `GET /graphs/:id` to allow access if `is_public` is true, even without a token.
    - Add `PUT /graphs/:id/share` endpoint to toggle `is_public` status.
- **Frontend**:
    - Add "Share" button in `GraphToolbar`.
    - Create a `ShareModal` to toggle public status and copy the public link.
    - Update `GraphEditor` to handle "Read-Only" mode for visitors (hide edit buttons).

## Implementation Steps
1.  **Backend**: Add `is_public` column and update API access control.
2.  **Frontend**: Implement `ShareModal` and Read-Only logic.
3.  **PWA**: Install plugin and configure manifest.

I will start with **Step 1 & 2: Public Sharing**, as it's a core feature for the "Sharing Square" concept.
