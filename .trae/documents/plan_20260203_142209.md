# Phase 3 Part 2: PWA Implementation

I will now implement PWA support to make the application installable and capable of offline caching.

## 1. Installation
- **Install**: `vite-plugin-pwa` (as dev dependency).

## 2. Configuration (`vite.config.ts`)
- **Plugin Setup**: Configure `VitePWA` with:
    - `registerType: 'autoUpdate'`: For seamless updates.
    - `includeAssets`: favicon.svg, robots.txt, etc.
    - `manifest`:
        - **Name**: "Knowledge Map AI"
        - **Short Name**: "KnowledgeMap"
        - **Description**: "AI-powered 3D Knowledge Graph Editor"
        - **Theme Color**: "#ffffff" (or match brand color)
        - **Icons**: I will configure it to use existing assets or placeholders, but ideally we need 192x192 and 512x512 PNGs. I will try to use `favicon.svg` as the source or generate basic PNGs if possible, or just point to `favicon.svg` for now (though PNG is standard).

## 3. HTML Updates (`index.html`)
- **Meta Tags**: Add `theme-color`, `apple-touch-icon`, and `description`.

## 4. Icon Generation (Best Effort)
- Since we only have `favicon.svg`, I will use it for the PWA icons configuration. SVG is scalable, but PWA manifests strictly require PNGs for many platforms.
- **Action**: I will check if I can quickly convert/create a simple 192/512 PNG from the SVG or create a placeholder. For now, I'll configure the manifest to point to standard paths (`/pwa-192x192.png`, etc.) and users can replace them later, OR I can use the SVG if the platform supports it (some do, but PNG is safer).
- **Better Approach**: I'll create a simple script or use a tool if available, but simplest is to just configure the manifest and let the user know to add the PNG files. *However*, to be proactive, I will try to see if I can write a simple SVG-to-PNG utility or just use the SVG file reference in the manifest as a fallback.

## 5. Implementation Steps
1.  **Install**: `npm install -D vite-plugin-pwa`.
2.  **Config**: Update `vite.config.ts`.
3.  **HTML**: Update `index.html`.
4.  **Reload**: Ensure the service worker registers.

This will complete the "offline-ready" requirement.
