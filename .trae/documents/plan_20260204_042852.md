## 1. 项目现状深度分析

### 1.1 项目结构与技术架构
- **前端 (Frontend)**: React 18 + Vite + TailwindCSS + Zustand + React Query。核心是 `GraphEditor` (3D图谱) 和 `LearningMode` (学习模式)。
- **后端 (Backend)**: Express.js + Supabase (PostgreSQL + pgvector)。采用 Service 层架构 (`aiService`, `graphService`, `taskService`)。
- **基础设施**: Redis (BullMQ 任务队列), Docker 支持。
- **AI 集成**: 多模型策略 (Deepseek, Aliyun, Volcengine)，涵盖文本生成、推理和 Embedding。

### 1.2 核心业务流
1.  **知识构建**: 用户通过文本/文件/URL -> AI 解析 -> 生成节点与关系 -> 3D 可视化。
2.  **知识内化**: 节点 -> 生成学习卡片/题目 -> FSRS 算法调度复习 -> 掌握度可视化。
3.  **任务处理**: 耗时操作（批量生成、深度解析）通过 BullMQ 异步处理，SSE 推送状态。

### 1.3 现有技术债务与风险
-   **硬编码配置**: AI 模型名称 (如 `doubao-seed-1-8-251228`) 和图谱视觉参数直接写在代码中，难以维护。
-   **类型安全不足**: 后端存在 `any` 类型使用，部分接口缺乏严格的 Request/Response Schema 校验。
-   **错误处理不统一**: 部分控制器直接抛出异常，缺乏统一的错误拦截和用户友好的前端反馈。
-   **测试缺失**: 核心业务逻辑（AI 生成流、FSRS 调度）缺乏单元测试和集成测试。
