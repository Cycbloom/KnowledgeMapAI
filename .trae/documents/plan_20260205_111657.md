# 2D 思维导图实现方案

## 🎯 核心需求

1. **2D 俯视角视图** - 像地图一样的平面视图
2. **基于学习状态的动态颜色** - 不使用固定颜色
3. **美观的节点样式** - 多层圆环、花纹设计
4. **数据库扩展** - 存储学习状态相关的颜色配置

## 📊 学习状态颜色系统

### 状态定义
- **已掌握** - 绿色系
- **待复习** - 橙色系
- **未解锁** - 灰色系
- **新节点** - 蓝色系
- **学习中** - 紫色系

## 🎨 节点样式设计

### 多层圆环设计
```
外圈 - 主要颜色（学习状态）
  ↓
中圈 - 次要颜色（渐变效果）
  ↓
内圈 - 发光效果
  ↓
中心点 - 核心颜色
```

### 样式变体
1. **基础样式** - 单圈 + 中心点
2. **双环样式** - 外圈 + 内圈 + 中心点
3. **三环样式** - 外圈 + 中圈 + 内圈 + 中心点
4. **花纹样式** - 虚线圈、点状圈等

### SVG 实现
使用原生 SVG 组件，支持：
- 渐变填充
- 发光效果（filter）
- 动画过渡
- 响应式尺寸

## 🔧 实现步骤

### 第一步：安装依赖
```bash
npm install d3-force
```

### 第二步：扩展类型定义
- 添加 `LearningStatus` 类型
- 扩展 `Node` 接口，添加学习状态字段
- 添加节点样式配置类型

### 第三步：创建颜色配置
- 创建 `LEARNING_STATUS_COLORS` 配置
- 创建 `NODE_STYLE_CONFIG` 配置
- 支持主题适配（dark/light）

### 第四步：创建节点样式组件
- `NodeRing` - 可复用的圆环组件
- `MindMapNode` - 完整的节点组件（多层圆环）
- 支持多种样式变体

### 第五步：创建 2D 布局算法
- 使用 `d3.forceSimulation` 创建 2D 力导向布局
- 根据节点级别设置不同的力参数
- 支持节点固定位置

### 第六步：创建画布组件
- `MindMapCanvas` - 主画布组件
- 实现缩放、平移、拖拽
- 渲染节点和连线

### 第七步：集成到 GraphOutline
- 添加 `mindmap` 视图模式
- 添加视图切换按钮
- 保持功能一致性

### 第八步：数据库扩展
- 添加节点学习状态表（如果需要）
- 添加用户自定义颜色配置表
- 更新 API 接口

## 🎨 节点样式示例

### 三环节点
```tsx
<NodeRing 
  radius={40}
  strokeWidth={3}
  color={statusColors.primary}
  opacity={0.8}
/>
<NodeRing 
  radius={32}
  strokeWidth={2}
  color={statusColors.secondary}
  opacity={0.6}
/>
<NodeRing 
  radius={24}
  strokeWidth={1.5}
  color={statusColors.glow}
  opacity={0.4}
/>
<Circle 
  r={8}
  fill={statusColors.primary}
/>
```

### 花纹变体
- 虚线圈：`strokeDasharray="4 4"`
- 点状圈：`strokeDasharray="2 4"`
- 渐变：使用 `<linearGradient>`
- 发光：使用 `<filter>`

## 🚀 后续优化

1. **动画效果** - 使用 framer-motion 添加平滑过渡
2. **交互反馈** - 悬停、选中时的视觉反馈
3. **性能优化** - 虚拟化大量节点
4. **自定义样式** - 用户可自定义颜色和样式
5. **导出功能** - 导出为 SVG 或 PNG

## ⚠️ 注意事项

1. **颜色对比度** - 确保在 dark/light 模式下都清晰可见
2. **性能考虑** - 大量节点时优化渲染
3. **响应式设计** - 适配不同屏幕尺寸
4. **可访问性** - 支持键盘导航和屏幕阅读器
