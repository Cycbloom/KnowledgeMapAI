# 节点聚焦高亮功能实现计划

## 1. 状态管理扩展
- 在 `useGraphEditorState.ts` 中添加聚焦相关状态：
  - `focusedNodeId`: 当前聚焦的节点ID
  - `focusedNodeIds`: 需要高亮的节点集合（选中节点 + 父节点 + 所有子节点）
  - `focusedLinkIds`: 需要高亮的连接线集合

## 2. 工具函数创建
- 在 `graphUtils.ts` 中添加以下函数：
  - `getFocusedNodes()`: 使用BFS遍历获取选中节点的所有子节点（包括所有层级）
  - `getParentNodes()`: 获取选中节点的所有父节点
  - `getFocusedLinks()`: 根据聚焦节点集合计算相关连接线

## 3. MindMapCanvas 组件修改
- 接收 `focusedNodeIds` 和 `focusedLinkIds` 作为新props
- 将聚焦信息传递给 `MindMapNode` 和 `MindMapLink` 组件
- 添加背景遮罩层（可选），让非聚焦区域更暗

## 4. MindMapNode 组件修改
- 添加 `isFocused` prop 判断节点是否在聚焦集合中
- 修改 `getTextVisibility` 函数：当 `isFocused=true` 时，强制文字可见且不透明度为1
- 根据 `isFocused` 调整节点透明度：
  - 聚焦节点：正常透明度
  - 非聚焦节点：降低透明度（如0.3）

## 5. MindMapLink 组件修改
- 添加 `isFocused` prop
- 根据 `isFocused` 调整连接线样式：
  - 聚焦连接线：正常或更高亮
  - 非聚焦连接线：降低透明度（如0.1）

## 6. GraphEditor 页面集成
- 在 `onNodeClick` 处理中计算聚焦节点集合
- 更新 `focusedNodeId`、`focusedNodeIds` 和 `focusedLinkIds` 状态
- 点击空白处时清除聚焦状态

## 7. 可选优化
- 添加聚焦模式切换按钮（类似现有的 Focus Mode）
- 添加动画过渡效果，使聚焦切换更平滑
- 支持键盘快捷键（如 Esc 退出聚焦模式）
