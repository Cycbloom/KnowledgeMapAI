# 思维导图性能优化方案

## 优化目标
解决思维导图缩进/操作时的卡顿问题，提升整体渲染性能

## 具体优化措施

### 1. 布局计算优化 (MindMapCanvas.tsx)
- 使用 `useMemo` 缓存布局计算结果
- 添加防抖机制，避免频繁重新计算布局
- 优化依赖项，只在必要时触发重新计算

### 2. 节点组件优化 (MindMapNode.tsx)
- 使用 `React.memo` 包装组件，避免不必要的重新渲染
- 使用 `useMemo` 缓存 rings 数组、textVisibility 等计算结果
- 优化事件处理函数，使用 `useCallback`

### 3. 链接组件优化 (MindMapLink.tsx)
- 使用 `React.memo` 包装组件
- 使用 `useMemo` 缓存路径数据计算
- 优化颜色和样式的计算逻辑

### 4. 大纲视图优化 (GraphOutline.tsx)
- 优化树结构计算的 `useMemo` 依赖项
- 使用虚拟化渲染（如果节点数量很大）
- 优化递归渲染逻辑

### 5. 状态管理优化 (GraphEditor.tsx)
- 优化 `lockedNodeIds`、`masteredNodeIds` 等计算的依赖项
- 使用 `useCallback` 优化事件处理函数
- 减少不必要的状态更新

## 预期效果
- 显著减少缩进/操作时的卡顿
- 提升整体渲染流畅度
- 降低 CPU 使用率
