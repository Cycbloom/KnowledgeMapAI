# 知识分支探索功能实现计划

## 🎯 功能目标
实现类似"故事线"的交互式知识分支探索系统，用户可以在节点上查看 AI 建议的多个分支方向，选择后创建节点，形成探索路径。

## 📦 实现内容

### 1. 新增分支预览组件
- **文件**: `src/components/GraphEditor/BranchPreview.tsx`
- 功能: 在节点周围显示 AI 建议的分支方向（虚线/半透明卡片）
- 交互: 点击分支卡片后创建真实节点

### 2. 修改 AI 操作逻辑
- **文件**: `src/hooks/useGraphAIOperations.ts`
- 新增 `handleBranchExplore` 方法
- 新增 `handleCreateBranch` 方法（从预览创建真实节点）
- 新增 `handleGetBranchSuggestions` 方法（获取分支建议）

### 3. 新增 API 端点
- **文件**: `api/routes/ai.ts`
- 新增 `/ai/branch-suggestions` 端点
- 专门用于生成分支建议（不创建节点）
- 返回结构化的分支数据（标题、描述、优先级）

### 4. 探索路径管理
- **文件**: `src/hooks/useExplorationPath.ts` (新建)
- 管理用户的探索历史
- 支持路径回溯和分支切换
- 记录每个分支的选择时间

### 5. 时间轴视图组件
- **文件**: `src/components/GraphEditor/ExplorationTimeline.tsx`
- 可选的侧边栏视图
- 按时间顺序显示探索路径
- 支持点击跳转到历史节点

### 6. 工具栏新增功能
- **文件**: `src/components/GraphEditor/GraphToolbar.tsx`
- 新增"探索分支"模式切换按钮
- 新增"时间轴视图"切换按钮
- 在选中节点时显示"探索分支"快捷按钮

### 7. 画布集成
- **文件**: `src/components/GraphEditor/MindMapCanvas.tsx`
- 集成分支预览组件
- 处理分支预览的显示/隐藏
- 处理分支点击事件

### 8. 状态管理
- **文件**: `src/hooks/useGraphEditorState.ts`
- 新增 `explorationMode` 状态（是否在分支探索模式）
- 新增 `branchSuggestions` 状态（当前分支建议）
- 新增 `explorationPath` 状态（探索历史）

### 9. 类型定义
- **文件**: `src/types/index.ts`
- 新增 `BranchSuggestion` 类型
- 新增 `ExplorationPathItem` 类型
- 新增 `ExplorationMode` 类型

## 🔄 工作流程

1. 用户在节点上点击"探索分支"按钮
2. 调用 AI API 获取分支建议（3-5 个）
3. 在节点周围显示分支预览卡片（虚线连接）
4. 用户点击某个分支
5. 创建真实节点和连线
6. 记录到探索路径
7. 可选：在时间轴视图中查看完整探索历史

## 🎨 UI 特性

- 分支预览使用虚线连接，半透明样式
- 分支卡片显示标题和简短描述
- 支持鼠标悬停查看完整描述
- 已探索的分支用实线高亮
- 未探索的分支用虚线显示
- 时间轴视图支持折叠/展开

## 📊 数据结构

```typescript
interface BranchSuggestion {
  id: string;
  title: string;
  description: string;
  priority: 'high' | 'medium' | 'low';
  estimatedDifficulty: 1-5;
  relatedTopics: string[];
}

interface ExplorationPathItem {
  nodeId: string;
  nodeTitle: string;
  timestamp: Date;
  branchChoice: string;
  parentNodeId?: string;
}
```
