# 思维导图模板系统实现计划

## 1. 数据结构定义

### 1.1 类型定义
- 新增 `Template` 类型：包含模板基本信息、节点配置、边配置、画布布局配置
- 新增 `TemplateNode` 类型：节点标题、层级、AI 提示词模板、位置等
- 新增 `TemplateLayout` 类型：画布布局配置（坐标轴、标签、区域等）

### 1.2 数据库设计
- `templates` 表：存储模板数据
  - id, name, description, category, is_system, user_id
  - nodes (JSON), edges (JSON), layout (JSON)

## 2. 后端实现

### 2.1 API 接口
- `GET /api/templates` - 获取模板列表（系统预设 + 用户自定义）
- `GET /api/templates/:id` - 获取模板详情
- `POST /api/templates` - 创建自定义模板
- `PUT /api/templates/:id` - 更新模板
- `DELETE /api/templates/:id` - 删除模板
- `POST /api/graphs` - 创建图谱时支持 `template_id` 参数

### 2.2 模板应用逻辑
- 根据 template_id 获取模板数据
- 自动创建对应的节点和边
- 应用画布布局配置

## 3. 前端实现

### 3.1 组件开发
- `TemplateSelector` 组件：模板选择界面（网格展示、搜索、分类筛选）
- `TemplatePreview` 组件：模板预览（显示节点结构）
- `TemplateCard` 组件：单个模板卡片（名称、描述、预览图）

### 3.2 Dashboard 改造
- 修改"新建图谱"弹窗，增加"选择模板"步骤
- 两步流程：先选模板，再填写图谱信息
- 支持跳过模板选择（创建空白图谱）

### 3.3 模板管理页面
- 新增 `/templates` 路由
- 展示用户自定义模板
- 支持创建、编辑、删除自定义模板

## 4. 预设学习模板

### 4.1 基础学习模板
- **概念学习**：主题 → 定义 → 特点 → 示例 → 应用
- **问题解决**：问题 → 原因分析 → 解决方案 → 实施步骤 → 预期效果

### 4.2 编程学习模板
- **编程基础**：主题 → 核心概念 → 语法规则 → 代码示例 → 常见错误

### 4.3 学科学习模板
- **历史学习**：事件背景 → 经过 → 影响 → 相关事件
- **科学实验**：实验目的 → 假设 → 材料 → 步骤 → 结果 → 结论

## 5. AI 集成

### 5.1 提示词模板系统
- 每个模板节点支持配置 AI 提示词模板
- 支持变量替换：`{主题}`、`{父节点内容}` 等
- 生成时自动注入上下文

### 5.2 上下文传递
- 生成节点内容时，获取父节点和兄弟节点的内容
- 作为 context 传递给 AI API

## 6. 画布布局系统

### 6.1 布局类型
- **四象限布局**：显示坐标轴和象限标签
- **时间轴布局**：显示时间线
- **流程图布局**：显示流程方向箭头

### 6.2 布局配置
- 坐标轴配置（显示/隐藏、标签、位置）
- 区域划分（象限、时间区间等）
- 节点自动分配规则
