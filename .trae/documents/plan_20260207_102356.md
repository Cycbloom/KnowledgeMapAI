# AI 助教功能实现计划

## 功能概述
增强现有的ChatDialog，实现一个能够通过对话逐步构建知识图谱的AI助教。

- 修改 `/ai/chat` 端点，增加助教模式参数

## 关键设计决策

1. **对话模式**：
   - 自由模式：用户主导，助教被动回答
   - 引导模式：助教主导，按照既定学习流程

2. **节点生成**：
   - 自动提取对话中的关键概念
   - 显示建议卡片，用户确认后添加
   - 支持批量添加

3. **上下文感知**：
   - 传递当前选中节点 ID
   - 传递用户学习进度
   - 传递图谱结构摘要

4. **动画设计**：
   - 新节点：缩放从 0 到 1 + 淡入
   - 高亮：脉冲效果
   - 持续时间：500ms

## 预期效果

- 用户可以通过对话与助教自由交流
- 助教可以从对话中提取概念并建议添加到图谱
- 用户确认后，新节点以动画形式出现在图谱中
- 助教能够根据用户进度调整对话内容
- 支持线性学习和跳跃式探索
