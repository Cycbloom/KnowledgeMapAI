# 使用 Docker 部署 Qwen3-TTS-0.6B 模型并集成到 KnowledgeMap 项目

## 实施计划

### 1. 创建 Docker TTS 服务

* 创建 `api/tts/` 目录结构

* 编写 `Dockerfile`（基于 Python 3.12，安装 qwen-tts、fastapi、uvicorn）

* 创建 `requirements.txt`（包含 qwen-tts、fastapi、uvicorn、pydantic 等依赖）

* 创建 `server.py` FastAPI 服务，提供 TTS API 端点

* 创建 `tts_model.py` 封装 Qwen3-TTS 模型调用

* 创建 `.dockerignore` 优化构建

### 2. Docker Compose 配置

* 更新项目根目录的 `docker-compose.yml`

* 添加 tts-service 服务配置

* 配置端口映射（如 8001:8000）

* 配置环境变量和模型路径

* 配置与主应用的网络连接

### 3. 后端 API 集成

* 在 `api/routes/ai.ts` 中添加 `/api/ai/tts` 端点

* 创建 TTS 请求的验证 schema（在 `api/schemas/index.ts`）

* 实现调用 Docker TTS 服务的逻辑（通过 HTTP）

* 支持流式音频输出

### 4. 前端集成

* 更新 `src/types/index.ts`，添加 TTS 配置类型

* 扩展 `src/hooks/useTextToSpeech.ts`，支持选择 TTS 模式（浏览器/本地模型）

* 更新 `src/components/GraphEditor/ChatDialog.tsx`，添加 TTS 模式切换

* 更新 `src/services/api.ts`，添加 TTS API 调用方法

### 5. 配置和文档

* 更新 `.env.example`，添加 TTS 服务相关配置

* 创建 `api/tts/README.md` 说明如何使用 Docker 部署

## 技术架构

* **Docker 容器**: Python 3.12 + FastAPI + Qwen3-TTS

* **端口**: 8001（TTS 服务）

* **通信**: Node.js 后端通过 HTTP 调用 Docker TTS 服务

* **前端**: React，可选择浏览器 TTS 或 Docker 本地模型 TTS
