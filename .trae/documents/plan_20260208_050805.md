# TTS 服务 GPU 加速配置计划

## 目标
将 Qwen3-TTS 服务从 CPU 迁移到 GPU，提升语音合成速度（预计提升 5-10 倍）

## 前置要求
- NVIDIA GPU（支持 CUDA 11.8+）
- 已安装 NVIDIA 驱动
- 已安装 NVIDIA Container Toolkit（nvidia-docker2）

## 实施步骤

### 1. 更新 Dockerfile
- 将基础镜像从 `python:3.12-slim` 改为 `nvidia/cuda:12.1.0-runtime-ubuntu22.04`
- 安装 Python 3.12 和必要的系统依赖
- 安装 CUDA 相关的 PyTorch 版本

### 2. 更新 requirements.txt
- 将 `qwen-tts>=0.1.0` 改为支持 CUDA 的版本
- 添加 CUDA 相关依赖（如 `torch` 带 CUDA 支持）

### 3. 更新 docker-compose.yml
- 添加 GPU 配置（`deploy.resources.reservations.devices`）
- 配置 NVIDIA runtime
- 调整内存限制（GPU 模式可能需要更多内存）

### 4. 更新 TTS_DEPLOYMENT.md
- 更新 GPU 模式的部署说明
- 添加 GPU 模式的性能对比
- 更新故障排除部分

### 5. 验证和测试
- 重新构建 Docker 镜像
- 启动服务并验证 GPU 是否被正确识别
- 测试语音合成功能
- 对比 CPU 和 GPU 模式的性能

## 预期效果
- 首次请求：从 10-30 秒降至 5-8 秒
- 后续请求：从 3-5 秒降至 0.5-1.5 秒（RTX 3060）或 <1 秒（RTX 4090）
