# 区域控制功能优化计划

## 问题分析

### 问题1：菜单消失
点击区域控制的复选框后，次级菜单会消失，用户体验不流畅。用户希望点击后菜单保持打开状态，可以连续操作多个区域。

**原因**：
- 次级菜单通过 CSS `group-hover` 显示
- 状态更新触发组件重新渲染，hover 状态丢失

**解决方案**：
- 为次级菜单添加状态控制，使用 `useState` 管理展开/收起
- 点击复选框时不关闭菜单

### 问题2：区域角度不更新
隐藏区域后，只是隐藏了节点，但区域的角度范围没有改变。用户希望隐藏区域后，其他区域重新分配角度。

**示例**：
- 原来6个区域，每个60度
- 隐藏1个后，变成5个区域，每个72度

**原因**：
- `regions` 计算时角度基于所有骨干模块数量
- 没有过滤掉被折叠的区域

**解决方案**：
- 修改 `regions` 计算逻辑
- 过滤掉被折叠的区域
- 只为可见区域计算角度

## 实施步骤

### 步骤1：修改 GraphToolbar 菜单保持逻辑
- 为次级菜单添加 `useState` 控制展开状态
- 点击复选框时不触发菜单关闭
- 需要手动管理次级菜单的显示/隐藏

### 步骤2：修改 GraphEditor.tsx 中 regions 计算
- 在计算角度时过滤掉 `collapsedRegions` 中的区域
- 只为可见区域分配角度
- 保持区域的原始顺序

### 步骤3：修改 QuadrantCanvas.tsx
- 确保只渲染可见的区域
- 节点位置根据新的角度计算

### 步骤4：运行类型检查
- `npm run check`
