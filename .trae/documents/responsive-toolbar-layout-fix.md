# 响应式工具栏布局修复计划

## 问题分析

### 1. 图谱地图界面工具栏 (GraphMapToolbar.tsx)

**当前问题：**
- 工具栏使用固定布局 `flex items-center justify-between`
- 左侧包含：返回按钮、标题、统计信息、来源图谱返回按钮
- 右侧包含：过滤按钮组（4个选项）、刷新、领域生成、AI分析、创建图谱、创建关系
- **没有任何响应式处理**，宽度变窄时所有元素挤压重叠，甚至竖向排列

**代码位置：** `src/components/GraphMap/GraphMapToolbar.tsx`

### 2. 首页工具栏行 (Dashboard.tsx)

**当前问题：**
- 搜索框和操作按钮行在中等宽度（平板尺寸）时可能出现排版问题
- 虽然有 `isMobile` 处理，但 `isTablet` 区间可能处理不够完善
- 按钮组在宽度变窄时可能挤压或换行不美观

**代码位置：** `src/pages/Dashboard.tsx`（第 432-635 行的操作按钮区域）

---

## 解决方案

### 方案一：图谱地图工具栏响应式改造

**改造策略：**

1. **引入响应式断点检测**
   - 使用现有的 `useIsMobile` hook 获取 `isMobile` 和 `isTablet` 状态

2. **左侧区域改造**
   - 移动端：只显示返回按钮和标题，统计信息隐藏或简化
   - 平板端：显示返回按钮、标题、简化统计信息

3. **右侧区域改造**
   - **过滤按钮组**：
     - 桌面端：显示全部 4 个过滤按钮
     - 平板端：显示 2 个常用按钮 + 下拉菜单
     - 移动端：使用下拉选择器替代按钮组
   - **操作按钮**：
     - 桌面端：显示所有按钮
     - 平板端：隐藏次要按钮文字，只显示图标
     - 移动端：将部分按钮收入"更多"菜单

4. **布局结构调整**
   ```
   桌面端：[左侧内容] ←→ [过滤组] [操作按钮]
   平板端：[左侧内容] ←→ [过滤下拉] [主要操作图标]
   移动端：[返回] [标题] ←→ [更多菜单]
   ```

### 方案二：首页工具栏行响应式优化

**改造策略：**

1. **搜索框区域**
   - 当前已有较好的响应式处理
   - 优化中等宽度时的按钮显示

2. **操作按钮区域**
   - 桌面端：显示全部按钮（导入、图谱地图、新建图谱、AI生成）
   - 平板端：隐藏"图谱地图"按钮，或将其移入更多菜单
   - 移动端：当前已有 FAB 按钮处理，保持不变

## 技术细节

### 响应式断点定义

根据项目现有的 `useIsMobile` hook：
- `isMobile`: 宽度 < 768px
- `isTablet`: 宽度 >= 768px 且 < 1024px
- 桌面端: 宽度 >= 1024px

### 图谱地图工具栏具体改造

**过滤按钮组改造：**
- 添加一个下拉选择器组件，在移动端/平板端使用
- 保留现有的按钮组，在桌面端显示

**操作按钮改造：**
- 创建一个"更多操作"下拉菜单
- 移动端将大部分操作收入菜单，只保留最常用的"创建关系"按钮

### 首页工具栏具体改造

**按钮组优化：**
- 使用 `flex-wrap` 允许按钮换行
- 或者在中等宽度时隐藏部分次要按钮
