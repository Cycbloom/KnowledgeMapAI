# 调度器 UI 优化：滚动事件隔离 + Header 精简

## 问题分析

### 问题 1：滚动事件冒泡导致误触发
当前 `useScrollDirection` 监听 `main` 元素的 `wheel` 事件，但下方队列/看板/时间轴/列表视图内部也有滚动，`wheel` 事件会冒泡到 `main`，导致在队列视图内滚动时智能推荐栏也跟着折叠/展开。

**根因**：没有区分"在推荐栏区域滚动"和"在队列视图内滚动"。

**解决方案**：改为只在推荐栏区域（而非整个 main）监听 `wheel` 事件。将 `mainRef` 改为指向推荐栏的容器 div，这样只有鼠标在推荐栏上方滚动时才会触发折叠/展开。

### 问题 2：Header 占用空间过大
当前 header 包含：
- 标题行（图标 + 标题 + 按钮组）— `py-4`，约 56px
- 统计行（4 个统计徽章）— `mt-4`，约 36px
- 学习路径过滤行 — `mt-3 pt-3`，约 36px

合计约 128px，再加上推荐栏（展开约 300-500px），上半部分总共 428-628px，严重挤压下方视图空间。

**解决方案**：
1. 将标题行和统计行合并为一行（标题左侧，统计右侧），节省垂直空间
2. 减小 padding（`py-4` → `py-2.5`，`mt-4` → `mt-2`）
3. 将统计徽章从独立行移到标题行右侧，与按钮组同行显示
4. 学习路径过滤行减小间距

## 实施步骤

### Step 1: 修改 `useScrollDirection` hook
- 新增 `shouldIgnoreEvent` 配置项，允许调用方自定义哪些 wheel 事件应被忽略
- 或更简单的方案：将 hook 的 ref 改为指向推荐栏容器而非 main 元素

**最终方案**：将 `mainRef` 改为指向推荐栏外层容器 div，这样只有鼠标在推荐栏区域滚动时才会触发折叠/展开，队列视图内的滚动不会冒泡触发。

### Step 2: 修改 `Scheduler.tsx`
- 将 `mainRef` 改为 `recommendationRef`，指向推荐栏容器 div
- 移除 `main` 元素上的 ref
- 将 ref 绑定到推荐栏外层的 div 上
- 精简 Header 布局：
  - 合并标题行和统计行为一行
  - 减小 padding 和 margin
  - 统计信息移到标题行右侧（桌面端），移动端保持换行

### Step 3: 验证
- 运行 `npm run check` 和 `npm run lint`
