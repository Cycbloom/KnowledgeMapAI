# 任务调度器卡片UI紧凑化优化计划

## 问题分析

根据用户提供的截图和反馈，当前任务调度器中的卡片存在以下问题：
1. **高度过高**：卡片内部padding和margin过大，导致整体高度偏高
2. **信息展示不够紧凑**：各元素之间间距过大，视觉上显得松散
3. **影响浏览效率**：在时间轴和看板视图中，过高的卡片导致可视区域内的任务数量减少

## 影响范围

本次优化主要针对以下组件：
- [TaskCard.tsx](src/components/Scheduler/TaskCard.tsx) - 看板视图和时间轴视图共用的任务卡片组件

## 优化方案

### 1. 卡片外层容器优化
**当前状态**：
- 外层 padding: `p-3 pl-4`
- 圆角: `rounded-xl`

**优化措施**：
- 减少 padding 至 `p-2 pl-3`
- 保持圆角不变或调整为 `rounded-lg`（更紧凑）

### 2. 状态标签区域优化
**当前状态**：
- 标签容器 margin-bottom: `mb-1.5`
- 标签内边距: `px-1.5 py-0.5`
- 字体大小: `text-[10px]`

**优化措施**：
- 减少标签容器 margin-bottom 至 `mb-1`
- 保持标签内边距和字体大小不变（已经比较紧凑）

### 3. 标题区域优化
**当前状态**：
- 标题 margin-bottom: `mb-1`
- 字体大小: `font-medium` (默认14px)

**优化措施**：
- 减少标题 margin-bottom 至 `mb-0.5`
- 保持字体大小不变

### 4. 描述文本区域优化
**当前状态**：
- 描述文本 margin-bottom: `mb-2`
- 行数限制: `line-clamp-2`
- 字体大小: `text-xs`

**优化措施**：
- 减少描述文本 margin-bottom 至 `mb-1.5`
- 改为单行显示: `line-clamp-1` 或保持 `line-clamp-2` 但减少间距

### 5. 学习路径信息区域优化
**当前状态**：
- 容器 margin-bottom: `mb-2`
- 图标大小: `size={12}`

**优化措施**：
- 减少容器 margin-bottom 至 `mb-1.5`
- 可选：减小图标大小至 `size={11}`

### 6. 进度条区域优化（长期任务）
**当前状态**：
- 上边距: `mt-2`
- 下边距: `mb-2`
- 进度条高度: `h-1.5`

**优化措施**：
- 减少上边距至 `mt-1.5`
- 减少下边距至 `mb-1.5`
- 保持进度条高度不变

### 7. 子任务区域优化（重点优化项）
**当前状态**：
- 容器上边距: `mt-2`
- 容器下边距: `mb-2`
- 按钮最小高度: `min-h-[44px]`
- 按钮内边距: `py-2`
- 子项内边距: `p-2`
- 子项复选框最小尺寸: `min-h-[44px] min-w-[44px]`

**优化措施**：
- 减少容器上边距至 `mt-1.5`
- 减少容器下边距至 `mb-1.5`
- **移除按钮的 min-h-[44px]`（这是无障碍要求的最小点击区域，但在卡片内部可以适当减小）
- 减少按钮内边距至 `py-1.5`
- 减少子项内边距至 `p-1.5`
- **减小复选框尺寸**：移除 `min-h-[44px] min-w-[44]`，改为更小的尺寸

### 8. 底部元数据区域优化
**当前状态**：
- 容器 gap: `gap-3`
- 图标大小: `size={12}`
- 字体大小: `text-xs`

**优化措施**：
- 减少容器 gap 至 `gap-2`
- 保持图标和字体大小不变

### 9. 操作按钮区域优化
**当前状态**：
- 区域 padding: `px-3 py-2`
- 按钮 padding: `p-2.5`
- 按钮最小尺寸: `min-h-[44px] min-w-[44px]`
- 图标大小: `size={16}`

**优化措施**：
- 减少区域 padding 至 `px-2 py-1.5`
- 减少按钮 padding 至 `p-2`
- **减小按钮最小尺寸**：移除 `min-h-[44px] min-w-[44px]`，改为 `min-h-[36px] min-w-[36px]`
- 减小图标大小至 `size={14}`

## 预期效果

1. **高度降低约 20-30%**：通过减少各个区域的padding和margin
2. **视觉更紧凑**：信息密度提高，但仍保持良好的可读性
3. **提升浏览效率**：相同可视区域内可显示更多任务卡片
4. **保持美观性**：不会因为过度压缩而显得拥挤

2. **暗色模式兼容**：所有样式修改需同时考虑亮色和暗色模式
3. **拖拽功能不受影响**：确保修改后卡片的拖拽交互正常工作
4. **动画效果保持**：framer-motion 的动画效果应继续正常工作
