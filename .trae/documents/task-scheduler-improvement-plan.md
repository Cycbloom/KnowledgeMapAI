# 任务调度系统改进计划

## 一、用户反馈的问题与需求

### 1. 当前存在的问题

#### 1.1 详情页面简陋
- 信息不全（题目、描述等缺失）
- 功能单一，缺乏工作台概念
- 需要作为"工作台"集成多种功能

#### 1.2 设置界面无法打开 ✅ 已修复
- **问题原因**: 设置面板使用 `overflow-hidden` 导致内容被裁剪，且 z-index 不够高
- **解决方案**: 将设置面板改为模态框形式，使用 `fixed inset-0 z-50` 确保在最上层显示
- **修改文件**:
  - `src/pages/Scheduler.tsx` - 重构设置面板为模态框
  - `src/components/Scheduler/TimeSlotSettings.tsx` - 更新样式和布局

#### 1.3 任务模板系统未完成
- 缺少长期任务模板功能
- 例如：背单词模板、刷题模板等

### 2. 功能改进需求

#### 2.1 任务进度系统增强
- 添加任务完成进度追踪
- 支持多种交付物类型：
  - 完成题目数量
  - 掌握知识点数量
  - 自定义进度指标
- 与知识图谱、研究系统联动

#### 2.2 详情页面重构为"工作台"
- 集成任务完整信息
- 连接知识图谱
- 连接外部资源（网页链接）
- 预留外部软件操作接口（暂不实现）：
  - 发送 API 请求
  - 打开文件
  - 打开 Markdown 编辑器

#### 2.3 智能调度算法改进
**当前问题：**
- 队列采用先进先出（FIFO）模式
- 缺乏智能调度

**改进方向：**
- 考虑截止日期
- 动态优先级调整
- 工作负载平衡

**架构讨论：队列 vs 任务池**
- 当前：三级队列（Q0/Q1/Q2），任务在队列内按位置排序
- 提议：改为任务池模式，从池中智能选取任务
- 拖动任务 = 改变优先级
