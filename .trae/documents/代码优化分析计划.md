# KnowledgeMap 代码优化分析计划

## 项目概述

KnowledgeMap 是一个基于知识图谱的学习应用，技术栈：
- **前端**: React 18 + TypeScript + Vite + TailwindCSS + Zustand + React Query
- **后端**: Express.js + TypeScript
- **数据库**: Supabase (PostgreSQL + pgvector)
- **缓存**: Redis (备用 NodeCache)
- **AI集成**: DeepSeek, 阿里云, 火山引擎

## 二、待优化项

### 2.1 高优先级 (P0)

#### 2.1.1 API 路由重复挂载问题

**问题**: `api/app.ts` 中存在路由重复挂载
```typescript
// 第112行和第118行重复
app.use('/api/auth', rateLimiters.auth, authRoutes)
app.use('/api/ai', rateLimiters.ai, aiRoutes)
```

**优化方案**: 删除重复的路由挂载

**涉及文件**: `api/app.ts`

---

#### 2.1.2 MindMapNode memo 比较函数不完整

**问题**: `src/components/GraphEditor/MindMapNode.tsx` 的 React.memo 比较函数缺少关键 props

**当前代码**:
```typescript
export const MindMapNode = React.memo(MindMapNodeComponent, (prevProps, nextProps) => {
  return (
    prevProps.node.id === nextProps.node.id &&
    prevProps.selected === nextProps.selected &&
    // ... 缺少 nodeStatus, colorScheme, coloringMode 等
  );
});
```

**优化方案**: 添加缺失的 props 比较，避免不必要的重渲染

**涉及文件**: `src/components/GraphEditor/MindMapNode.tsx`

---

#### 2.1.3 GraphEditor 组件进一步拆分

**问题**: `src/pages/GraphEditor.tsx` 仍有 1053 行代码

**优化方案**:
1. 提取视图切换逻辑到独立组件 `ViewModeRenderer.tsx`
2. 提取分支操作逻辑到 `useBranchOperations.ts` (已部分完成)
3. 提取演示模式逻辑到 `usePresentationMode.ts`

**涉及文件**: 
- `src/pages/GraphEditor.tsx`
- `src/components/GraphEditor/ViewModeRenderer.tsx` (新建)

---

### 2.2 中优先级 (P1)

#### 2.2.1 视图组件懒加载

**问题**: TimelineView、TreeView、PlanetView 同步导入

**当前代码**:
```typescript
import { TimelineView } from '../components/GraphEditor/views/TimelineView';
import { TreeView } from '../components/GraphEditor/views/TreeView';
import { PlanetView } from '../three/PlanetView';
```

**优化方案**: 使用 React.lazy 懒加载
```typescript
const TimelineView = lazy(() => import('../components/GraphEditor/views/TimelineView'));
const TreeView = lazy(() => import('../components/GraphEditor/views/TreeView'));
const PlanetView = lazy(() => import('../three/PlanetView'));
```

**涉及文件**: `src/pages/GraphEditor.tsx`

---

**涉及文件**: `vite.config.ts`
