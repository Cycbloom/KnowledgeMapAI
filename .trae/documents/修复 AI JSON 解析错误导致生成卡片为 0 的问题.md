导致“生成 0 张卡片”的核心原因极有可能是 **AI 返回的 JSON 格式包含了 Markdown 代码块标记（如 \`\`\`json ... \`\`\`）**，而 `aiService.ts` 直接使用了 `JSON.parse`，导致解析失败并抛出异常，进而导致整个生成流程中断或返回空结果。

### 修复方案

我将分两步彻底解决这个问题：

1.  **增强 `aiService.ts` 的鲁棒性**：
    *   在解析 AI 返回的 JSON 之前，增加一个清洗步骤，自动去除 Markdown 代码块标记（` ```json` 和 ` ``` `）。
    *   增加 `try-catch` 块来捕获 `JSON.parse` 的错误，并在解析失败时尝试进行简单的文本修复或记录详细的错误日志，而不是让任务直接失败。

2.  **前端交互优化**：
    *   虽然主要问题在后端，但我会检查前端在收到 0 张卡片时的提示信息，确保给用户更明确的反馈（例如：“AI 生成内容格式有误，正在重试”或具体的错误原因），而不是仅仅显示“已生成 0 张”。

### 执行计划

1.  **修改 `aiService.ts`**：
    *   实现 `cleanJsonString` 辅助函数，用于去除 Markdown 标记。
    *   在 `generateCards` 和 `expandKnowledge` 方法中应用此函数。
    *   完善错误捕获逻辑，确保即使 AI 返回格式稍有偏差也能尽可能提取数据。

2.  **验证**：
    *   这一修改将同时修复“批量生成”和“单独生成”中可能出现的 0 张卡片问题，因为它们底层都依赖 `aiService.ts`。
