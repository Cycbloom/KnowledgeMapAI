# 修复代码中的 TypeScript 错误

## 发现的问题

通过 `npx tsc --noEmit` 检测到 3 个 TypeScript 错误：

### 1. WeeklyReflection.tsx - 未使用的导入和变量

**文件**: [src/components/Scheduler/WeeklyReflection.tsx](file:///d:/KnowledgeMap/src/components/Scheduler/WeeklyReflection.tsx)

- **第 9 行**: `ScheduledTask` 被导入但从未使用
  ```typescript
  import { schedulerApi, ScheduledTask, TaskStats } from '../../services/api/scheduler';
  ```

- **第 67 行**: `tasks` 变量被解构声明但从未使用
  ```typescript
  const [stats, tasks, reviews, existingReview] = await Promise.all([...]);
  ```

### 2. Tasks.tsx - 类型错误

**文件**: [src/pages/Tasks.tsx](file:///d:/KnowledgeMap/src/pages/Tasks.tsx)

- **第 412 行**: 条件表达式的结果类型为 `unknown`，不能作为 `ReactNode` 渲染
  ```typescript
  {t.status === 'completed' && t.type === 'infinite_graph_expansion' && t.result?.source_graph_id && Boolean(t.result.source_graph_id) && (
    <button>...</button>
  )}
  ```
  
  问题在于 `t.result?.source_graph_id` 的类型推断为 `unknown`，导致整个条件表达式类型不正确。

## 修复方案

### 修复 1: WeeklyReflection.tsx

1. 移除未使用的 `ScheduledTask` 导入
2. 使用 `_` 前缀标记未使用的 `tasks` 变量（或直接忽略该解构位置）

### 修复 2: Tasks.tsx

添加类型断言或类型守卫来确保 `t.result.source_graph_id` 被正确识别为可渲染的类型：

```typescript
{t.status === 'completed' && t.type === 'infinite_graph_expansion' && 
  typeof t.result?.source_graph_id === 'string' && t.result.source_graph_id && (
    <button>...</button>
  )}
```

或者使用双重断言：
```typescript
{t.status === 'completed' && t.type === 'infinite_graph_expansion' && 
  Boolean(t.result?.source_graph_id) && (
    <button>...</button>
  )}
```
