## 问题分析

树形视图显示了7个节点，而实际图中只有5个节点，说明存在重复节点问题。

通过分析代码，我发现问题出在 `createTreeLayout` 函数中：

1. 当构建层次结构时，`buildHierarchy` 函数会递归地将子节点添加到父节点的子节点列表中
2. 当一个节点被多个父节点引用时（例如节点D同时是B和C的子节点），它会被多次添加到不同的父节点的子节点列表中
3. 当通过 `root.each` 遍历树结构时，这个节点会被访问多次，从而在 `layout.nodes` 中出现多次
4. 最终导致树形视图中显示重复的节点

## 解决方案

在 `createTreeLayout` 函数中，当通过 `root.each` 遍历树结构创建布局节点时，使用一个 Set 来跟踪已经添加的节点 ID，确保每个节点只被添加一次。

## 具体修改步骤

1. 打开 `src/utils/layouts/treeLayout.ts` 文件
2. 在 `createTreeLayout` 函数中，修改 `root.each` 遍历部分的代码
3. 添加一个 Set 来跟踪已经添加的节点 ID
4. 在添加节点到 `layoutNodes` 之前，检查该节点的 ID 是否已存在于 Set 中
5. 只有当节点 ID 不存在于 Set 中时，才将其添加到 `layoutNodes` 中

## 预期结果

修改后，树形视图将只显示实际的节点数量（5个），不再显示重复的节点。
