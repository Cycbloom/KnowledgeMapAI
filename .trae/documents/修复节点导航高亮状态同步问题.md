# 修复节点导航高亮状态同步问题

## 问题描述

在知识图谱页面右侧面板的节点详情中，点击"上一级"或"下一级"导航按钮切换节点时，知识图谱上的节点高亮/亮度设置没有跟随更新。

## 问题原因

在 [GraphSidebarManager.tsx:164-166](file:///d:\KnowledgeMap\src\components\GraphEditor\GraphSidebarManager.tsx#L164-L166) 中，`onRelatedNodeClick` 回调只更新了 `selectedNode` 状态：

```tsx
onRelatedNodeClick={(node) => {
  setSelectedNode(node);
}}
```

但是，节点高亮需要更新以下状态：
- `focusedNodeId` - 当前聚焦的节点ID
- `focusedNodeIds` - 需要高亮的节点集合（当前节点 + 祖先 + 后代）
- `focusedLinkIds` - 需要高亮的连线集合
- `forceShowTextIds` - 强制显示文本的节点集合

对比 [GraphEditor.tsx:411-423](file:///d:\KnowledgeMap\src\pages\GraphEditor.tsx#L411-L423) 中正确的 `handleNodeClick` 实现：

```tsx
const handleNodeClick = useCallback((node: GraphNode) => {
  const focusedNodes = getFocusedNodes(node.id, nodes, edges);
  const focusedLinks = getFocusedLinks(focusedNodes, edges);
  const directChildren = getDirectChildren(node.id, nodes, edges);
  
  setSelectedNode(node);
  setSelectedNodeIds(new Set([node.id]));
  setSidebarMode('detail');
  setFocusedNodeId(node.id);
  setFocusedNodeIds(focusedNodes);       // ← 缺少这个
  setFocusedLinkIds(focusedLinks);       // ← 缺少这个
  state.setForceShowTextIds(new Set([node.id, ...directChildren])); // ← 缺少这个
}, [...]);
```

## 修复方案

修改 `GraphSidebarManager.tsx` 中的 `onRelatedNodeClick` 回调，使其完整更新所有高亮相关状态。

### 修改文件

**文件**: [GraphSidebarManager.tsx](file:///d:\KnowledgeMap\src\components\GraphEditor\GraphSidebarManager.tsx)

需要从 `state` 中解构出额外的状态设置函数，并在 `onRelatedNodeClick` 中调用它们：

```tsx
const {
  // ... 现有解构
  setFocusedNodeId,
  setFocusedNodeIds, 
  setFocusedLinkIds,
  setForceShowTextIds,
} = state;
```

然后在 `onRelatedNodeClick` 中：

```tsx
onRelatedNodeClick={(node) => {
  const focusedNodes = getFocusedNodes(node.id, nodes, edges);
  const focusedLinks = getFocusedLinks(focusedNodes, edges);
  const directChildren = getDirectChildren(node.id, nodes, edges);
  
  setSelectedNode(node);
  setSelectedNodeIds(new Set([node.id]));
  setFocusedNodeId(node.id);
  setFocusedNodeIds(focusedNodes);
  setFocusedLinkIds(focusedLinks);
  setForceShowTextIds(new Set([node.id, ...directChildren]));
}}
```

### 需要导入的工具函数

在 `GraphSidebarManager.tsx` 顶部添加导入：

```tsx
import { getFocusedNodes, getFocusedLinks, getDirectChildren } from '../../lib/graphUtils';
```

## 验证步骤

1. 打开知识图谱页面
2. 选择一个有父节点或子节点的节点
3. 在右侧面板点击"上一级"或"下一级"按钮
4. 确认知识图谱上的节点高亮状态正确更新
