# 创建独立学习统计页面计划

为了提供更全面、清晰的学习数据分析，我将创建一个独立的 `/statistics` 页面，并迁移原首页的图表，同时增加新的预测和趋势分析功能。

## 1. 后端 API 开发 (`api/routes/statistics.ts`)
创建一个新的 API 路由 `/statistics`，提供聚合的统计数据：
- **学习热力图 (Heatmap)**: 过去一年的每日学习次数（迁移自 Dashboard）。
- **知识状态分布 (Distribution)**: 卡片在不同 FSRS 阶段（新、学习中、复习、重学）的分布（迁移自 Dashboard）。
- **复习预测 (Forecast)**: 未来 7 天每日需复习的卡片数量（**新增**）。
- **卡片增长趋势 (Growth)**: 过去 30 天每日新增卡片数量（**新增**）。
- **核心指标 (Key Metrics)**: 卡片总数、今日待复习数、已掌握卡片数等（**新增**）。

## 2. 前端页面开发 (`src/pages/Statistics.tsx`)
新建统计页面，采用清晰的网格布局展示数据：
- **顶部概览卡片**: 展示 4 个核心指标（总卡片、今日待复习、掌握进度、平均记忆稳定性）。
- **学习活跃度**: 展示全年的学习热力图（复用 `ActivityHeatmap`）。
- **数据可视化图表区**:
    - **复习预测柱状图**: 展示未来一周的学习压力。
    - **知识分布饼图**: 展示当前知识掌握情况（复用 `StatsOverview`）。
    - **增长趋势面积图**: 展示知识库的积累速度。

## 3. 页面迁移与优化
- **Dashboard (`src/pages/Dashboard.tsx`)**:
    - 移除原本占据大版面的热力图和分布图，使首页更专注于“开始学习”和“图谱管理”。
    - 添加一个“查看详细统计”的入口或保留精简版摘要。
- **导航栏 (`src/components/Layout.tsx`)**:
    - 在侧边栏添加 "统计分析" (`/statistics`) 链接，使用 `BarChart` 图标。
- **路由配置 (`src/App.tsx`)**:
    - 注册新的 `/statistics` 路由。

## 4. 技术栈
- **图表库**: 继续使用 `recharts` 实现新增的柱状图和面积图，保持风格统一。
- **数据获取**: 封装新的 `useStatistics` Hook。

此方案将把分散的统计信息整合为一个专业的数据分析中心，帮助用户更好地规划学习路径。
