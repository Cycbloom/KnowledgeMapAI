## 使用方式

这些组件已经创建完成，你可以在相应的页面中导入使用：

```tsx
// 在图谱编辑页面使用预览卡片（已集成）
import { NodePreviewCard } from '../components/GraphEditor/NodePreviewCard';

// 在布局中使用增强搜索（已存在，已增强）
import { GlobalSearch } from '../components/GlobalSearch';

// 在统计页面使用可视化组件
import { 
  KnowledgeHeatmap, 
  MasteryDistributionChart, 
  WeakPointsAnalysis,
  LearningTimeTrend,
  QuickStatsCards 
} from '../components/LearningStatsEnhanced';

// 使用标签系统
import { TagCloud, TagFilter, TagInput } from '../components/TagSystem';

// 使用快速笔记
import { QuickNotePanel, QuickNoteButton, QuickNoteList } from '../components/QuickNote';

// 使用关联发现
import { ConnectionDiscovery, NodeConnectionSuggestions } from '../components/ConnectionDiscovery';
```
