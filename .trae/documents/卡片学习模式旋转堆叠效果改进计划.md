# 卡片学习模式旋转堆叠效果改进计划

## 一、需求分析

### 当前实现
- **移动方式**：水平拖拽滑动（左滑/右滑）
- **动画效果**：卡片水平飞出，带有轻微旋转（±30度）
- **卡片显示**：单张卡片显示，切换时直接替换

### 目标效果
1. **旋转移动**：将水平滑动改为旋转移动，类似翻牌/转盘效果
2. **堆叠效果**：下一张卡片在当前卡片下方显示，形成卡牌堆叠视觉效果

## 二、技术方案

### 2.1 堆叠效果实现

**方案**：同时渲染多张卡片，通过 CSS 层叠和缩放实现堆叠视觉

```typescript
// 渲染 3 张卡片：当前卡片 + 后面 2 张
{quizCards.slice(currentCardIndex, currentCardIndex + 3).map((card, index) => {
  const isTopCard = index === 0;
  const stackOffset = index * 10; // Y轴偏移
  const stackScale = 1 - index * 0.05; // 缩放比例
  const stackZIndex = 10 - index; // 层级
  
  return (
    <motion.div
      key={card.id}
      style={{
        y: stackOffset,
        scale: stackScale,
        zIndex: stackZIndex,
      }}
      // 只有顶层卡片可交互
      drag={isTopCard ? "x" : false}
    >
      {/* 卡片内容 */}
    </motion.div>
  );
})}
```

```tsx
<div className="relative perspective-1000 h-[550px] md:h-[600px]">
  {/* 堆叠背景卡片 */}
  {quizCards.slice(currentCardIndex + 1, currentCardIndex + 3).map((card, index) => {
    const stackIndex = index + 1;
    return (
      <motion.div
        key={`stack-${card.id}`}
        className="absolute inset-0 bg-white dark:bg-slate-800 rounded-3xl shadow-lg"
        style={{
          y: stackIndex * 8,
          scale: 1 - stackIndex * 0.03,
          zIndex: 10 - stackIndex,
          opacity: 0.7 - stackIndex * 0.2,
        }}
      />
    );
  })}
  
  {/* 当前活动卡片 */}
  <AnimatePresence mode="popLayout">
    <motion.div
      key={cardKey}
      drag="x"
      dragConstraints={{ left: 0, right: 0 }}
      dragElastic={0.3}
      onDrag={(_, info) => {
        // 实时旋转
        setCardRotation(info.offset.x * 0.2);
        // 原有方向判断逻辑
        if (info.offset.x > 30) setDragDirection('right');
        else if (info.offset.x < -30) setDragDirection('left');
        else setDragDirection(null);
      }}
      onDragEnd={handleDragEnd}
      initial={{ scale: 0.95, opacity: 0, y: 20, rotate: 0, rotateY: 0 }}
      animate={{ 
        scale: 1, 
        opacity: 1, 
        y: 0, 
        rotate: 0, 
        rotateY: 0 
      }}
      exit={{ 
        x: swipeDirection === 'right' ? 500 : -500, 
        y: 80,
        opacity: 0,
        scale: 0.7,
        rotate: cardRotation * 2, // 增强旋转效果
        rotateY: swipeDirection === 'right' ? 90 : -90,
        transition: { duration: 0.4, ease: 'easeOut' }
      }}
      style={{ 
        transformOrigin: 'bottom center',
        rotate: cardRotation, // 拖拽时实时旋转
        zIndex: 10,
      }}
    >
      {/* 卡片内容保持不变 */}
    </motion.div>
  </AnimatePresence>
</div>
```

#### 3.3 修改 handleDragEnd 函数（约第191-221行）

```typescript
const handleDragEnd = (_: any, info: any) => {
  const threshold = 100;
  const velocity = info.velocity.x;
  const offset = info.offset.x;
  
  setDragDirection(null);
  setCardRotation(0); // 重置旋转
  
  const shouldSwipeRight = offset > threshold && velocity > 0;
  const shouldSwipeLeft = offset < -threshold && velocity < 0;
  
  if (shouldSwipeRight) {
    setSwipeDirection('right');
    handleSwipeRate(3);
    setTimeout(() => {
      handleNextCard();
      setCardKey(k => k + 1);
      setSwipeDirection(null);
    }, 300); // 延长动画时间
  } else if (shouldSwipeLeft) {
    setSwipeDirection('left');
    handleSwipeRate(1);
    setTimeout(() => {
      handleNextCard();
      setCardKey(k => k + 1);
      setSwipeDirection(null);
    }, 300);
  }
};
```

## 四、视觉效果说明

### 4.1 堆叠效果
- 显示当前卡片 + 后2张卡片的边缘
- 后面的卡片逐渐缩小、下移、透明度降低
- 形成类似扑克牌堆叠的视觉效果

### 4.2 旋转移动效果
- 拖拽时：卡片跟随手指水平移动并旋转
- 释放后：卡片以大角度旋转飞出（类似飞牌效果）
- 下一张卡片从堆叠中"浮现"成为当前卡片

### 4.3 动画参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 堆叠卡片数量 | 2-3张 | 显示后续卡片边缘 |
| Y轴偏移 | 8px/层 | 卡片垂直间距 |
| 缩放比例 | 0.97/层 | 后面卡片缩小 |
| 透明度 | 0.7/0.5 | 后面卡片透明 |
| 旋转角度 | 拖拽距离×0.2 | 实时跟随 |
| 飞出旋转 | ±90度 | 大角度旋转 |
| 飞出翻转 | ±90度(rotateY) | 3D翻转效果 |
