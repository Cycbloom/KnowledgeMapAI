# 图谱地图拓展功能增强计划

## 需求分析

用户希望增强图谱地图的功能，帮助用户：
1. **跨领域知识发现**：从一个知识领域拓展到另一个知识领域
2. **知识点层级拓展**：在图谱（领域）层级和知识点（节点）层级都能进行拓展
3. **智能推荐**：发现潜在的知识连接和学习方向

## 层级结构说明

```
图谱地图（Graph Map）
├── 图谱/领域层级（Graph Level）
│   ├── 图谱 A（如：机器学习）
│   │   ├── 知识点层级（Node Level）
│   │   │   ├── 节点：线性回归
│   │   │   ├── 节点：决策树
│   │   │   └── 节点：神经网络
│   ├── 图谱 B（如：深度学习）
│   └── 图谱关系
│       ├── prerequisite（前置知识）
│       ├── extension（扩展知识）
│       └── related（相关知识）
```

## 功能设计

### 功能一：快速创建关联图谱

**场景**：用户选中一个图谱，想快速创建其前置知识图谱或扩展知识图谱

**功能点**：
- 在图谱详情面板中添加"创建前置图谱"和"创建扩展图谱"按钮
- 点击后弹出创建面板，填写新图谱名称
- 自动创建图谱并建立关系
- 可选择是否使用 AI 自动生成初始内容

**UI 位置**：GraphMap 页面的图谱详情面板

### 功能二：智能推荐相关图谱

**场景**：用户想了解当前图谱可能与哪些其他图谱相关

**功能点**：
- 分析当前图谱的关键词/主题
- 与其他图谱进行相似度匹配
- 推荐可能的前置知识、扩展知识、相关知识
- 用户可以一键创建推荐的关系

**UI 位置**：图谱详情面板中的"推荐"区域

### 功能三：知识拓展建议（AI 分析）

**场景**：用户想了解应该学习哪些新领域

**功能点**：
- AI 分析当前图谱地图的整体结构
- 发现"孤岛图谱"（没有任何关系的图谱）
- 建议可能缺失的前置知识领域
- 建议可能的扩展学习方向
- 生成学习路径建议

**UI 位置**：工具栏新增"AI 分析"按钮，结果展示在侧边面板

### 功能四：快速创建新图谱

**场景**：用户想在图谱地图中快速添加新的知识领域

**功能点**：
- 工具栏添加"创建图谱"按钮
- 支持双击空白区域创建图谱
- 创建后可立即建立与其他图谱的关系

**UI 位置**：工具栏 + 画布交互

### 功能五：图谱合并建议

**场景**：发现内容相似度高的图谱，建议合并

**功能点**：
- 检测内容高度重叠的图谱
- 提供合并建议
- 合并时保留关系连接

**UI 位置**：AI 分析面板中展示

## 技术实现方案

### 1. 后端 API 扩展

#### 1.1 智能推荐 API
```typescript
// GET /graphs/:id/recommendations
// 返回推荐的相关图谱
interface GraphRecommendation {
  graph_id: string;
  graph_title: string;
  recommendation_type: 'prerequisite' | 'extension' | 'related';
  confidence: number; // 0-1
  reason: string; // 推荐理由
}
```

#### 1.2 AI 分析 API
```typescript
// POST /graphs/map/analyze
// 分析图谱地图，返回建议
interface MapAnalysis {
  isolated_graphs: string[]; // 孤岛图谱
  missing_prerequisites: { graph_id: string; suggested_topics: string[] }[];
  suggested_paths: { from: string; to: string; via: string[] }[];
  merge_suggestions: { graph_ids: string[]; reason: string }[];
}
```

#### 1.3 快速创建图谱 API
```typescript
// POST /graphs/quick-create
// 快速创建图谱并建立关系
interface QuickCreateGraph {
  title: string;
  description?: string;
  relation_to?: {
    graph_id: string;
    type: 'prerequisite' | 'extension' | 'related';
  };
  auto_generate_content?: boolean; // 是否 AI 生成初始内容
}
```

**第一阶段：快速创建功能**
1. 创建 `QuickCreateGraphPanel` 组件

1. 创建 `GraphRecommendations` 组件

1. 创建 `MapAnalysisPanel` 组件
2. 实现后端分析 API
3. 展示分析结果和建议

**第四阶段：交互优化**
1. 双击空白区域创建图谱
2. 拖拽创建关系
3. 快捷键支持
