# 图谱地图集成题目生成功能计划

## 需求概述

在图谱地图（GraphMap）页面的节点浮动面板中集成题目生成功能，允许用户直接从图谱地图节点快速生成相关知识点题目，无需跳转到学习中心页面。

## 现有功能分析

### 图谱地图页面 (GraphMap.tsx)
- 点击节点显示左侧浮动面板
- 面板功能：打开图谱、添加关系、快速创建关联图谱、AI智能拓展
- 已有 `selectedGraphId` 状态管理选中的图谱

### 学习中心页面 (LearningMode.tsx)
- 使用 `KnowledgePointSelector` 组件选择知识点
- 使用 `GenerateCardsModal` 组件配置题目参数
- 调用 `api.ai.batchGenerateCards(node_ids, config)` 生成题目

### 关键组件
- `KnowledgePointSelector` - 知识点选择器组件
- `GenerateCardsModal` - 题目生成配置对话框

## 实现方案

### 方案一：复用现有组件（推荐）

在图谱地图浮动面板中添加"生成题目"按钮，点击后：
1. 弹出知识点选择对话框（复用 `KnowledgePointSelector` 逻辑）
2. 选择知识点后弹出题目配置对话框（复用 `GenerateCardsModal`）
3. 调用 API 生成题目

**优点**：
- 代码复用度高
- 用户体验一致
- 开发工作量小

### 方案二：内嵌式设计

直接在浮动面板中嵌入知识点选择和题目配置功能。

**优点**：
- 操作更流畅
- 无需弹窗

**缺点**：
- 浮动面板空间有限
- 开发工作量大

**最终选择：方案一**

## 详细实现步骤

### 步骤 1：创建知识点选择对话框组件

**文件**：`src/components/GraphMap/NodeSelectorModal.tsx`

创建一个可复用的知识点选择对话框，用于在图谱地图中选择知识点。

**功能**：
- 接收 `graphId` 参数
- 加载该图谱下的所有知识点
- 支持搜索和多选
- 返回选中的知识点ID列表

### 步骤 2：修改 GraphMap.tsx 添加题目生成入口

**文件**：`src/pages/GraphMap.tsx`

在浮动面板中添加"生成题目"按钮：

**修改内容**：
1. 导入新组件和 API
2. 添加状态管理：
   - `isNodeSelectorOpen` - 控制知识点选择对话框
   - `isGenerateCardsModalOpen` - 控制题目配置对话框
   - `selectedNodeIds` - 存储选中的知识点ID
   - `selectedNodeTitle` - 用于显示的标题
3. 在浮动面板的"AI智能拓展"按钮下方添加"生成题目"按钮
4. 实现题目生成逻辑

### 步骤 3：实现题目生成流程

**流程**：
1. 用户点击"生成题目"按钮
2. 弹出知识点选择对话框
3. 用户选择知识点后确认
4. 弹出题目配置对话框
5. 用户配置参数后确认
6. 调用 `api.ai.batchGenerateCards` API
7. 显示成功提示，引导用户查看任务

### 步骤 4：添加成功提示和任务跳转

**功能**：
- 生成任务提交成功后显示提示消息
- 提供"查看任务"按钮跳转到任务列表页面

## 技术细节

### API 调用

```typescript
const result = await api.ai.batchGenerateCards(selectedNodeIds, {
  count: 10,
  types: ['qa', 'choice', 'true_false', 'multi_choice', 'fill_in_the_blank'],
});
```

### 消息提示

使用 `useMessageStore` 显示成功/失败消息：

```typescript
addMessage({
  type: 'success',
  content: '题目自动生成任务已提交至后台',

  action: {

    onClick: () => navigate('/tasks'),
  },
});
```

## 风险评估

| 风险 | 影响 | 缓解措施 |
|-----|------|---------|
| 图谱下无知识点 | 功能无意义 | 显示提示信息，引导用户先添加知识点 |
| API 调用失败 | 用户体验差 | 显示错误提示，提供重试选项 |
| 大量知识点加载慢 | 性能问题 | 添加加载状态，限制单次选择数量 |
