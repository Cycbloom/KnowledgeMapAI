# 图谱思维导图实现计划

## 需求分析

用户希望创建一个新的"图谱思维导图"功能：
- **节点**：每个节点代表一个知识图谱（学习方向）
- **边**：体现图谱之间的关系（prerequisite/extension/related）
- **复用**：尽可能复用现有的知识图谱组件

## 现有资源

### 数据层
- `graph_relations` 表：存储图谱之间的关系
  - `source_graph_id`：源图谱
  - `target_graph_id`：目标图谱
  - `relation_type`：关系类型（prerequisite/extension/related）
  - `context`：关系描述

### API 层
- `api.graphs.getRelations(id)`：获取单个图谱的关联关系
- `api.graphs.createPrerequisiteGraph()`：创建前置图谱
- `api.graphs.createPrerequisiteGraphs()`：批量创建前置图谱

### 前端组件
- `MindMapCanvas`：思维导图画布（可复用）
- `MindMapNode`：节点渲染组件（可复用）
- `MindMapLink`：连线渲染组件（可复用）
- `mindmapLayout.ts`：力导向布局算法（可复用）
- `RelatedGraphsPanel`：关联图谱面板（可参考）

## 关键实现细节

### 1. 数据转换
将图谱数据转换为现有 Node/Edge 格式，以便复用布局算法和渲染组件：

```typescript
// 图谱 -> Node
{
  id: graph.id,
  title: graph.title,
  content: graph.description,
  level: calculateGraphLevel(graph, relations), // 基于连接数计算
  x_position: graph.x_position || 0,
  y_position: graph.y_position || 0,
}

// 关系 -> Edge
{
  id: relation.id,
  source_node_id: relation.source_graph_id,
  target_node_id: relation.target_graph_id,
  relationship_type: relation.relation_type,
}
```

### 2. 关系类型颜色映射
```typescript
const RELATION_COLORS = {
  prerequisite: '#3B82F6', // 蓝色 - 前置知识
  extension: '#10B981',    // 绿色 - 扩展知识
  related: '#F59E0B',      // 橙色 - 相关知识

```

### 3. 节点级别计算
```typescript
// 基于图谱的连接数计算级别
const calculateGraphLevel = (graph, allRelations) => {
  const connections = allRelations.filter(
    r => r.source_graph_id === graph.id || r.target_graph_id === graph.id
  ).length;
  
  if (connections >= 5) return 'root';
  if (connections >= 3) return 'core';
  if (connections >= 2) return 'sub';
  if (connections >= 1) return 'normal';
  return 'leaf';
};
```

### 4. 复用 MindMapCanvas
通过适配器模式，将图谱数据转换为 MindMapCanvas 期望的格式：

```typescript
// GraphMapCanvas.tsx
const GraphMapCanvas = ({ graphs, relations, ...props }) => {
  // 转换数据
  const nodes = useMemo(() => convertGraphsToNodes(graphs), [graphs]);
  const edges = useMemo(() => convertRelationsToEdges(relations), [relations]);
  
  // 复用 MindMapCanvas
  return (
    <MindMapCanvas
      nodes={nodes}
      edges={edges}
      {...props}
    />
  );
};
```
