# 图谱收藏置顶功能实现计划

## 功能概述

在知识图谱列表（Dashboard）中添加收藏功能，用户可以点击星星/爱心图标收藏图谱，收藏的图谱会在列表最前面显示。

## 实现步骤

### 1. 数据库迁移

**文件**: `supabase/migrations/[timestamp]_add_favorite_to_graphs.sql`

- 在 `knowledge_graphs` 表中添加 `is_favorite` 字段（BOOLEAN，默认 false）
- 添加索引优化查询性能

```sql
ALTER TABLE knowledge_graphs 
ADD COLUMN is_favorite BOOLEAN DEFAULT false;

CREATE INDEX idx_knowledge_graphs_user_favorite 
ON knowledge_graphs(user_id, is_favorite DESC) 
WHERE deleted_at IS NULL;
```

### 2. 后端 API 修改

#### 2.1 更新类型定义

**文件**: `api/types/index.ts`

- 在 Graph 相关类型中添加 `is_favorite?: boolean` 字段

#### 2.2 添加收藏 API 端点

**文件**: `api/routes/graphs.ts`

- 新增 `PUT /graphs/:id/favorite` 端点
- 请求体: `{ is_favorite: boolean }`

#### 2.3 更新服务层

**文件**: `api/services/graphService.ts`

- 添加 `toggleFavorite` 方法
- 修改 `listGraphs` 方法，按 `is_favorite DESC, last_used_at DESC` 排序

### 3. 前端修改

#### 3.1 更新类型定义

**文件**: `src/types/index.ts`

- 在 `Graph` 接口中添加 `is_favorite?: boolean` 字段

#### 3.2 添加 API 方法

**文件**: `src/services/api/graphs.ts`

- 添加 `toggleFavorite(id: string, is_favorite: boolean)` 方法

#### 3.3 添加 React Query Mutation

**文件**: `src/hooks/useQueries.ts`

- 添加 `useToggleFavoriteMutation` hook

#### 3.4 修改 Dashboard 组件

**文件**: `src/pages/Dashboard.tsx`

- 在图谱卡片上添加收藏按钮（使用 `Star` 图标）
- 收藏状态：实心星星（黄色）
- 未收藏状态：空心星星
- 修改排序逻辑，收藏的图谱排在最前面

## UI 设计

- 收藏按钮位置：图谱卡片右上角，与删除按钮并列
- 图标：使用 lucide-react 的 `Star` 图标
- 交互：点击切换收藏状态，即时反馈（无需刷新）
- 视觉效果：
  - 已收藏：黄色实心星星
  - 未收藏：灰色空心星星
