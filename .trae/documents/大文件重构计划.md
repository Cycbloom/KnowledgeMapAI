## 二、重构方案

### 2.1 `src/services/api.ts` 拆分

**目标结构**：
```
src/services/api/
├── index.ts              # 统一导出，保持向后兼容
├── client.ts             # 基础请求客户端
├── auth.ts               # 认证 API
├── graphs.ts             # 图谱 API
├── nodes.ts              # 节点 API
├── edges.ts              # 边 API
├── ai.ts                 # AI 相关 API
├── study.ts              # 学习相关 API
├── tasks.ts              # 任务 API
├── templates.ts          # 模板 API
├── achievements.ts       # 成就 API
├── learningPaths.ts      # 学习路径 API
├── rag.ts                # RAG API
├── autoGraph.ts          # 自动图谱 API
└── search.ts             # 搜索 API
```

**拆分步骤**：
1. 创建 `src/services/api/` 目录
2. 提取 `client.ts`：request 函数、handleResponse、getHeaders、CSRF 逻辑、Token 刷新
3. 按业务域拆分各 API 模块
4. 创建 `index.ts` 统一导出
5. 更新 `src/services/api.ts` 为 re-export 文件

## 四、注意事项

1. **保持向后兼容**：使用 re-export 保持原有导入路径
2. **逐步迁移**：每次只重构一个文件
3. **测试验证**：每次重构后运行 TypeScript 编译检查
4. **避免循环依赖**：注意模块间的依赖关系

- 每个文件不超过 300 行
- 模块职责单一
- 便于独立测试
