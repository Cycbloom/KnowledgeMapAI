# 大纲视图等级标签颜色改进计划

## 问题描述

大纲视图中节点旁边的等级标签（如 "root"、"core" 等）目前使用统一的灰色样式，需要根据节点等级添加对应的颜色，使其与圆点颜色标识保持一致。

## 当前实现

### 列表视图模式（第 388-390 行）
```tsx
<span className="text-[10px] text-slate-400 bg-slate-100 dark:bg-slate-800 px-1 py-0.5 rounded uppercase">
  {level}
</span>
```

### 树状视图模式（第 495-500 行）
```tsx
{node.level && (
  <span className={`text-[10px] uppercase ml-2 px-1 rounded hidden group-hover:inline-block
     ${selectedNodeId === node.id ? 'bg-blue-100 dark:bg-blue-800 text-blue-700' : 'bg-slate-100 dark:bg-slate-800 text-slate-500'}`}>
    {node.level}
  </span>
)}
```

## 解决方案

使用 `getLevelColors` 函数返回的颜色配置，为等级标签设置对应的背景色和文字颜色。

### 等级对应颜色
| 等级 | 背景色 | 文字色 |
|------|--------|--------|
| root | `#F5F3FF` (浅紫) | `#5B21B6` (深紫) |
| core | `#FEF2F2` (浅红) | `#991B1B` (深红) |
| sub | `#FFFBEB` (浅橙) | `#92400E` (深橙) |
| normal | `#EFF6FF` (浅蓝) | `#1E40AF` (深蓝) |
| leaf | `#ECFDF5` (浅绿) | `#065F46` (深绿) |

## 修改内容

### 文件：`src/components/GraphEditor/GraphOutline.tsx`

#### 1. 列表视图模式（第 388-390 行）
```tsx
// 修改前
<span className="text-[10px] text-slate-400 bg-slate-100 dark:bg-slate-800 px-1 py-0.5 rounded uppercase">
  {level}
</span>

// 修改后
<span 
  className="text-[10px] px-1 py-0.5 rounded uppercase"
  style={{ 
    backgroundColor: getLevelColors(level).background,
    color: getLevelColors(level).text
  }}
>
  {level}
</span>
```

#### 2. 树状视图模式（第 495-500 行）
```tsx
// 修改前
{node.level && (
  <span className={`text-[10px] uppercase ml-2 px-1 rounded hidden group-hover:inline-block
     ${selectedNodeId === node.id ? 'bg-blue-100 dark:bg-blue-800 text-blue-700' : 'bg-slate-100 dark:bg-slate-800 text-slate-500'}`}>
    {node.level}
  </span>
)}

// 修改后
{node.level && (
  <span 
    className="text-[10px] uppercase ml-2 px-1 rounded hidden group-hover:inline-block"
    style={{ 
      backgroundColor: selectedNodeId === node.id 
        ? getLevelColors(node.level).primary 
        : getLevelColors(node.level).background,
      color: selectedNodeId === node.id 
        ? '#ffffff' 
        : getLevelColors(node.level).text
    }}
  >
    {node.level}
  </span>
)}
```

## 预期效果

修改后，等级标签将显示对应的颜色：

- 🟣 **ROOT** - 紫色标签
- 🔴 **CORE** - 红色标签
- 🟠 **SUB** - 橙色标签
- 🔵 **NORMAL** - 蓝色标签
- 🟢 **LEAF** - 绿色标签

选中状态时，标签背景变为该等级的主色，文字变为白色，更加醒目。

## 影响范围

- 仅影响大纲视图的视觉显示
- 不影响任何功能逻辑
- 与现有的 `getLevelColors` 函数兼容
