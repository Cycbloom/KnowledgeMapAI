# 大纲视图节点等级颜色标识改进计划

## 问题描述

大纲视图（GraphOutline）中的节点等级颜色标识不明显。当前实现使用 `getLevelColors().background` 作为颜色，这是非常浅的背景色，视觉上几乎无法区分不同等级的节点。

### 当前代码位置
- `src/components/GraphEditor/GraphOutline.tsx` 第 383 行和第 488 行

### 当前问题
```tsx
<div 
  className="w-2 h-2 rounded-full shrink-0"
  style={{ backgroundColor: getLevelColors(node.level || 'leaf').background }}
/>
```
使用的是 `background` 颜色，这些是极浅的背景色：
- root: `#F5F3FF` (极浅紫色)
- core: `#FEF2F2` (极浅红色)
- sub: `#FFFBEB` (极浅橙色)
- normal: `#EFF6FF` (极浅蓝色)
- leaf: `#ECFDF5` (极浅绿色)

## 解决方案

将颜色标识从 `background` 改为 `primary` 颜色，这样不同等级的节点会有明显不同的颜色：

### 等级对应颜色（primary）
| 等级 | 颜色 | Hex 值 |
|------|------|--------|
| root | 紫色 | `#8B5CF6` |
| core | 红色 | `#EF4444` |
| sub | 橙色 | `#F59E0B` |
| normal | 蓝色 | `#3B82F6` |
| leaf | 绿色 | `#10B981` |

## 修改内容

### 文件：`src/components/GraphEditor/GraphOutline.tsx`

需要修改两处：

1. **列表视图模式**（第 381-384 行）
```tsx
// 修改前
<div 
  className="w-2 h-2 rounded-full shrink-0"
  style={{ backgroundColor: getLevelColors(node.level || 'leaf').background }}
/>

// 修改后
<div 
  className="w-2 h-2 rounded-full shrink-0"
  style={{ backgroundColor: getLevelColors(node.level || 'leaf').primary }}
/>
```

2. **树状视图模式**（第 486-489 行）
```tsx
// 修改前
<div 
  className="w-2 h-2 rounded-full shrink-0 mr-2"
  style={{ backgroundColor: getLevelColors(node.level || 'leaf').background }}
/>

// 修改后
<div 
  className="w-2 h-2 rounded-full shrink-0 mr-2"
  style={{ backgroundColor: getLevelColors(node.level || 'leaf').primary }}
/>
```

## 预期效果

修改后，大纲视图中的节点颜色标识将清晰显示：
- 🟣 紫色圆点 = 根节点 (root)
- 🔴 红色圆点 = 核心节点 (core)
- 🟠 橙色圆点 = 次级节点 (sub)
- 🔵 蓝色圆点 = 普通节点 (normal)
- 🟢 绿色圆点 = 叶子节点 (leaf)

## 影响范围

- 仅影响大纲视图的视觉显示
- 不影响任何功能逻辑
- 与现有的 `getLevelColors` 函数兼容，无需新增代码
