# 学习路径展示与大纲联动优化计划

## 需求分析

用户提出两个核心需求：

1. **学习路径详细展示**：当前闯关学习模式中的学习路径面板展示过于简略，需要展示各个学习项的详细信息（第一个、第二个、第三个...的顺序、状态、预计时间等）。

2. **大纲视图与学习路径联动**：当用户在闯关学习模式中选中一个学习路径时，左侧大纲视图应该切换为显示该学习路径的节点顺序（从上到下的线性列表），而不是当前的图谱层级大纲。

## 当前实现分析

### 相关文件

1. **LearningMode.tsx** - 闯关学习模式主页面
   - 左侧：`GraphOutline` 组件显示知识图谱大纲
   - 右侧面板：可切换显示 "AI 助教" 或 "学习路径"（`LearningPathPanel`）

2. **GraphOutline.tsx** - 大纲视图组件
   - 基于图谱节点和边构建树状/列表结构
   - 支持搜索、筛选、排序、多选等功能

3. **LearningPathPanel.tsx** - 学习路径面板
   - 显示已保存的学习路径列表（简略）
   - 点击"查看详情"跳转到独立页面

4. **LearningPathDetail.tsx** - 学习路径详情页
   - 完整展示学习路径节点列表
   - 每个节点有状态、预计时间、难度等信息

## 实现方案

### 方案概述

采用"模式切换"方案：在闯关学习模式中，左侧大纲视图支持两种模式：
- **图谱大纲模式**（默认）：显示知识图谱的层级结构
- **学习路径模式**：显示选中学习路径的节点顺序列表

### 具体实现步骤

#### 步骤 1：创建学习路径大纲组件

创建新组件 `LearningPathOutline.tsx`，专门用于展示学习路径的节点列表：

**功能特性**：
- 显示学习路径的节点顺序（第1、第2、第3...）
- 每个节点显示：标题、状态（待学习/学习中/已完成）、预计时间、难度
- 支持点击节点跳转到对应学习内容
- 当前正在学习的节点高亮显示
- 显示整体进度条

**位置**：`src/components/LearningPath/LearningPathOutline.tsx`

#### 步骤 2：修改 LearningMode.tsx 添加模式切换

**修改内容**：
- 添加状态：`outlineMode: 'graph' | 'learning-path'`
- 添加状态：`selectedLearningPathId: string | null`
- 当用户在右侧面板选择学习路径时，切换大纲模式
- 根据模式渲染 `GraphOutline` 或 `LearningPathOutline`

**交互逻辑**：
- 用户点击右侧面板的学习路径 → 左侧大纲切换为学习路径模式
- 用户点击"返回图谱大纲"按钮 → 切换回图谱大纲模式
- 用户点击学习路径中的节点 → 导航到对应知识点

#### 步骤 3：增强 LearningPathPanel 的展示

**修改内容**：
- 在学习路径列表中展开显示节点预览（前5个节点）
- 添加"切换到此路径"按钮，点击后：
  - 通知父组件切换大纲模式
  - 在左侧显示完整的学习路径节点列表
- 保留原有的"查看详情"按钮（跳转到详情页）

#### 步骤 4：实现大纲视图与学习路径的双向联动

**联动逻辑**：
- 右侧选择学习路径 → 左侧大纲切换为学习路径视图
- 左侧点击学习路径中的节点 → 右侧 AI 助教上下文更新
- 左侧点击"返回图谱大纲" → 切换回图谱大纲视图

#### 步骤 5：优化 UI/UX

**视觉设计**：
- 学习路径模式下，大纲顶部显示路径标题和进度
- 节点列表使用卡片式设计，清晰展示顺序
- 当前节点使用特殊样式高亮（如边框、背景色）
- 已完成节点显示勾选图标
- 添加平滑的切换动画

## 预期效果

1. **学习路径详细展示**：用户可以在闯关学习模式中看到学习路径的完整节点列表，包括顺序、状态、预计时间等信息。

2. **大纲视图联动**：当用户选择一个学习路径时，左侧大纲自动切换为学习路径视图，显示从上到下的学习顺序。

3. **灵活切换**：用户可以随时在"图谱大纲"和"学习路径"两种模式之间切换。

4. **学习进度可视化**：清晰展示当前学习进度，已完成、进行中、待学习的节点一目了然。

## 风险与注意事项

1. **性能考虑**：学习路径可能包含大量节点，需要考虑虚拟滚动或分页加载。

2. **状态同步**：确保学习路径节点的状态与知识图谱节点状态保持同步。

3. **移动端适配**：在小屏幕设备上，需要考虑左侧大纲的显示方式。

4. **数据获取**：需要确保学习路径数据包含足够的节点详情信息。
