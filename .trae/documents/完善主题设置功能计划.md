# 主题设置完善计划 (Theme Settings Enhancement Plan)

为了实现完整的主题设置功能，我们将对现有的主题机制进行升级，支持“跟随系统”模式，并在个人中心添加可视化的设置选项。

## 1. 核心逻辑重构 (Refactor useTheme Hook)

**文件**: `src/hooks/useTheme.ts`
目前 `useTheme` 仅支持 `light` 和 `dark` 两种手动模式，且仅在初始化时读取一次系统偏好。我们将对其进行重构：

* **新增状态**: 引入 `ThemeMode` 类型 (`'light' | 'dark' | 'system'`)。

* **系统监听**: 当模式为 `system` 时，实时监听 `window.matchMedia('(prefers-color-scheme: dark')` 的变化。

* **解析逻辑**: 区分“用户设置的模式”(`themeMode`) 和“当前实际应用的主题”(`resolvedTheme`)。

* **兼容性**: 保持 `toggleTheme` 方法，点击时将退出 `system` 模式并在 light/dark 间切换。

## 2. 个人中心 UI 升级 (Update Profile Page)

**文件**: `src/pages/Profile.tsx`
在个人中心页面新增“外观设置”模块：

* **位置**: 在“账号信息”和“AI 状态”之间，或作为独立卡片。

* **交互**: 提供三个选项卡/按钮：

  * 🌞 **浅色 (Light)**

  * 🌙 **深色 (Dark)**

  * 🖥️ **跟随系统 (System)**

* **视觉反馈**: 当前选中的模式高亮显示。

## 3. 组件适配 (Component Adaptation)

**文件**: `src/components/GraphEditor/GraphToolbar.tsx` (无需修改代码，但行为会变)

* 工具栏上的主题切换按钮将作为“快捷覆盖”开关。

* 当用户在工具栏点击切换时，会自动锁定为 `light` 或 `dark` 模式（退出 `system` 模式）。

* 若要恢复跟随系统，需前往个人中心设置。

## 实施步骤

1. 修改 `useTheme.ts`，增加 `system` 模式支持及监听逻辑。
2. 修改 `Profile.tsx`，引入 `Palette` (或类似) 图标，构建外观设置 UI。
3. 验证：

   * 切换系统/浅色/深色是否立即生效。

   * 调整操作系统主题时，`system` 模式下应用是否自动响应。

   * 刷新页面后设置是否保留。
