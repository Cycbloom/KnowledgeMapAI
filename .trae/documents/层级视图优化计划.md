# 层级视图优化计划

## 问题分析

### 问题1：缺少点击高亮功能
- **现状**：层级视图没有实现点击节点后高亮子树和祖先节点的功能
- **对比**：思维导图视图已有此功能，通过 `focusedNodeIds` 和 `focusedLinkIds` 实现
- **需求**：点击节点后，该节点及其子树和祖先节点正常显示，其他节点变暗淡

### 问题2：布局排列不合理
- **现状**：当前布局算法只是简单按 `level` 属性分组水平排列
- **问题**：
  - 相同层级的节点挨在一起，没有考虑父子关系
  - root 节点可能在子节点下面
  - 没有按照实际的树形结构排列

## 解决方案

### 1. 添加点击高亮功能

**修改文件**：`src/components/GraphEditor/views/HierarchyView.tsx`

- 添加 `focusedNodeIds` 和 `focusedLinkIds` props
- 添加 `focused` 和 `hasFocusMode` 属性到节点渲染
- 非聚焦节点添加暗淡效果（opacity 降低）

**修改文件**：`src/pages/GraphEditor.tsx`

- 向 HierarchyView 传递 `focusedNodeIds` 和 `focusedLinkIds` props

### 2. 重新设计布局算法

**修改文件**：`src/utils/layouts/hierarchyLayout.ts`

新布局算法设计：
1. **从 root 节点开始**：找到 level 为 'root' 的节点作为起点
2. **按树形结构排列**：
   - root 节点在最顶部
   - 子节点在父节点下方
   - 同一父节点的子节点水平排列
3. **考虑父子关系**：子节点应该在其父节点的下方展开，而不是和其他同 level 节点混在一起
4. **自动计算层级**：如果没有 level 属性，根据边的关系计算层级深度

具体实现：
```
1. 构建父子关系映射
2. 从 root 节点开始 BFS 遍历，计算每个节点的深度
3. 按深度分层，每层从上到下排列
4. 同一父节点的子节点水平排列在父节点下方
5. 计算每层的宽度，确保不重叠
```
