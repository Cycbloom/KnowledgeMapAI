# 提示词模板分类展示功能计划

## 背景

当前个人设置页面中的提示词模板管理功能将所有 16 个模板平铺展示，用户体验不佳。需要对模板进行分类展示，提高可读性和易用性。

## 当前状态

- 共有 16 个提示词模板
- 在 `PromptSettingsPanel.tsx` 中通过 `promptCodes` 数组平铺展示
- 没有分类结构

## 分类方案

将 16 个模板分为以下 4 个类别：

### 1. 知识图谱构建 (Graph Building)
| Code | 名称 |
|------|------|
| expand_knowledge | 知识扩展 |
| branch_suggestions | 分支建议 |
| recommend_connections | 推荐连线 |
| text_to_graph | 文本转图谱 |
| document_to_graph | 文档转图谱 |

### 2. 卡片生成 (Card Generation)
| Code | 名称 |
|------|------|
| generate_cards | 生成卡片（通用）|
| generate_cards_qa | 生成卡片：问答 |
| generate_cards_choice | 生成卡片：单选 |
| generate_cards_true_false | 生成卡片：判断 |
| generate_cards_multi_choice | 生成卡片：多选 |
| generate_cards_fill_blank | 生成卡片：填空 |
| generate_cards_essay | 生成卡片：论述 |

### 3. AI 对话 (AI Chat)
| Code | 名称 |
|------|------|
| chat | AI 对话 |
| tutor_chat | AI 助教 |
| generate_content | 内容生成 |

### 4. 其他工具 (Other Tools)
| Code | 名称 |
|------|------|
| term_annotation | 术语标注 |

## 实现方案

### 修改文件
- `src/components/PromptSettingsPanel.tsx`

### 具体改动

1. **新增分类数据结构**
   ```typescript
   const PROMPT_CATEGORIES = [
     {
       id: 'graph_building',
       name: '知识图谱构建',
       icon: 'Network',
       codes: ['expand_knowledge', 'branch_suggestions', 'recommend_connections', 'text_to_graph', 'document_to_graph']
     },
     {
       id: 'card_generation',
       name: '卡片生成',
       icon: 'Layers',
       codes: ['generate_cards', 'generate_cards_qa', 'generate_cards_choice', 'generate_cards_true_false', 
               'generate_cards_multi_choice', 'generate_cards_fill_blank', 'generate_cards_essay']
     },
     {
       id: 'ai_chat',
       name: 'AI 对话',
       icon: 'MessageSquare',
       codes: ['chat', 'tutor_chat', 'generate_content']
     },
     {
       id: 'other',
       name: '其他工具',
       icon: 'Wrench',
       codes: ['term_annotation']
     }
   ];
   ```

2. **添加分类折叠/展开功能**
   - 每个分类默认折叠
   - 点击分类标题展开/折叠
   - 使用 `useState` 管理展开状态

3. **UI 布局调整**
   - 分类标题带图标和展开/折叠箭头
   - 分类下方的模板列表仅在展开时显示
   - 保持原有的模板卡片样式

4. **新增图标导入**
   - 从 `lucide-react` 导入: `Network`, `Layers`, `MessageSquare`, `Wrench`, `ChevronDown`, `ChevronRight`

## 预期效果

- 用户进入提示词管理页面，看到 4 个折叠的分类
- 点击分类标题展开，查看该分类下的模板
- 模板编辑、重置等功能保持不变
- 界面更清晰，易于查找和管理
