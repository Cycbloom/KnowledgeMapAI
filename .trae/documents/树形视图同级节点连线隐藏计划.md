# 树形视图同级节点连线隐藏计划

## 问题描述

在树形视图中，同一层级的顶点之间不应该有连线。因为它们都在同一行，连线会导致视觉上看起来全部连在一起，影响可读性。

## 当前实现分析

### 关键文件
- `src/components/GraphEditor/views/TreeView.tsx` - 树形视图主组件
- `src/utils/layouts/treeLayout.ts` - 树形布局计算

### 当前连线逻辑
1. `treeLayout.ts` 计算节点位置，每个节点有 `x` 和 `y` 坐标
2. `TreeView.tsx` 中的 `visibleLinks` 过滤可见连线：
   ```typescript
   const visibleLinks = useMemo(() => {
     if (!layout) return [];
     const visibleNodeIds = new Set(visibleNodes.map(n => String(n.id).trim()));
     return layout.links.filter(link => {
       const sourceId = ...;
       const targetId = ...;
       return visibleNodeIds.has(sourceId) && visibleNodeIds.has(targetId);
     });
   }, [layout, visibleNodes]);
   ```

### 问题根源
当前只检查节点是否可见，没有检查连线两端节点是否在同一层级。

## 解决方案

在 `TreeView.tsx` 的 `visibleLinks` 过滤逻辑中，增加同级节点判断：
- 如果 source 和 target 节点的 `y` 坐标相同（或非常接近），则认为是同级节点
- 同级节点之间的连线不显示

### 判断逻辑
```typescript
// 判断是否为同级节点（y 坐标接近）
const isSameLevel = Math.abs(sourceNode.y - targetNode.y) < threshold;
// threshold 可以设为一个较小的值，如 10 像素
```

## 修改步骤

### 步骤 1: 修改 `TreeView.tsx` 中的 `visibleLinks` 计算逻辑

**文件**: `d:\KnowledgeMap\src\components\GraphEditor\views\TreeView.tsx`

**位置**: 第 114-122 行

**修改内容**:
1. 在过滤连线时，获取 source 和 target 节点的位置信息
2. 判断两个节点的 y 坐标是否接近
3. 如果 y 坐标接近（同级节点），则过滤掉该连线

**修改前**:
```typescript

  });

```

**修改后**:
```typescript
const visibleLinks = useMemo(() => {
  if (!layout) return [];
  const visibleNodeIds = new Set(visibleNodes.map(n => String(n.id).trim()));
  const nodesMap = new Map(layout.nodes.map(n => [String(n.id).trim(), n]));
  
  return layout.links.filter(link => {
    const sourceId = typeof link.source === 'string' ? String(link.source).trim() : String(link.source.id).trim();
    const targetId = typeof link.target === 'string' ? String(link.target).trim() : String(link.target.id).trim();
    
    if (!visibleNodeIds.has(sourceId) || !visibleNodeIds.has(targetId)) {
      return false;
    }
    
    // 过滤同级节点之间的连线（树形视图中同级节点在同一行，连线会造成视觉混乱）
    const sourceNode = nodesMap.get(sourceId);
    const targetNode = nodesMap.get(targetId);
    if (sourceNode && targetNode) {
      const SAME_LEVEL_THRESHOLD = 10; // 10像素阈值
      const isSameLevel = Math.abs(sourceNode.y - targetNode.y) < SAME_LEVEL_THRESHOLD;
      if (isSameLevel) {
        return false;
      }
    }
    
    return true;
  });
}, [layout, visibleNodes]);
```

## 影响范围

- 仅影响树形视图 (`TreeView.tsx`)
- 不影响脑图视图或其他视图
- 不修改数据库或后端逻辑
- 不修改边的数据，只是视觉上隐藏同级节点间的连线
