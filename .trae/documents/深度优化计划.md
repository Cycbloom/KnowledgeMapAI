# KnowledgeMap 深度优化计划

## 概述

本计划将对项目进行全面深度优化，涵盖安全性、性能、代码质量和用户体验四个方面。

---

## 一、高优先级优化（安全性和性能）

### 1.1 N+1 查询问题修复

**问题**: `api/services/graphService.ts` 中 `listGraphs` 方法存在 N+1 查询

**优化方案**:
- 创建 Supabase RPC 函数 `get_user_graphs_with_counts`
- 一次性获取图谱列表和节点数量
- 减少数据库查询次数

**涉及文件**:
- `api/services/graphService.ts`
- `supabase/migrations/` (新增 RPC 函数迁移)

### 1.2 文件上传安全加固

**问题**: `api/routes/ai.ts` 中文件上传只限制了大小

**优化方案**:
- 添加文件类型白名单验证
- 支持 PDF、TXT、MD、PNG、JPEG、WEBP
- 添加文件内容校验

**涉及文件**:
- `api/routes/ai.ts`

### 1.3 Token 过期检查

**问题**: `api/middleware/auth.ts` 中没有显式检查 token 过期时间

**优化方案**:
- 添加 session 过期检查
- 返回更明确的错误码
- 支持自动刷新机制

**涉及文件**:
- `api/middleware/auth.ts`

### 1.4 敏感信息日志过滤

**问题**: `api/middleware/errorHandler.ts` 中记录了完整的请求体

**优化方案**:
- 过滤 password、token、refreshToken、apiKey 等敏感字段
- 使用 `[REDACTED]` 替换敏感值

**涉及文件**:
- `api/middleware/errorHandler.ts`

---

## 二、中优先级优化（代码质量）

### 2.1 GraphEditor 组件拆分

**问题**: `src/pages/GraphEditor.tsx` 有 1148 行代码

**优化方案**:
- 提取 `useGraphEditorState` 到独立文件
- 提取 `useGraphEditorActions` 到独立文件
- 拆分视图切换逻辑到独立组件
- 提取工具栏组件

**涉及文件**:
- `src/pages/GraphEditor.tsx`
- `src/hooks/useGraphEditorState.ts` (新建)
- `src/hooks/useGraphEditorActions.ts` (新建)
- `src/components/GraphEditor/Toolbar.tsx` (新建)

### 2.2 API 服务文件拆分

**问题**: `src/services/api.ts` 有 844 行

**优化方案**:
- 拆分为 `api/auth.ts`
- 拆分为 `api/graphs.ts`
- 拆分为 `api/nodes.ts`
- 拆分为 `api/ai.ts`
- 拆分为 `api/study.ts`
- 创建 `api/index.ts` 统一导出

**涉及文件**:
- `src/services/api.ts`
- `src/services/api/` (新建目录)

### 2.3 批量更新优化

**问题**: `api/routes/nodes.ts` 中批量更新使用循环

**优化方案**:
- 创建 RPC 函数 `batch_update_positions`
- 使用单条 SQL 更新所有位置

**涉及文件**:
- `api/routes/nodes.ts`
- `supabase/migrations/` (新增 RPC 函数迁移)

### 2.4 视图组件懒加载

**问题**: TimelineView、TreeView、PlanetView 同步导入

**优化方案**:
- 使用 `React.lazy` 懒加载
- 添加 Suspense 包裹
- 减少初始包体积

**涉及文件**:
- `src/pages/GraphEditor.tsx`

## 三、低优先级优化（用户体验）

### 3.1 消息列表虚拟化

**问题**: RAGChatPanel 消息较多时可能卡顿

**优化方案**:
- 使用已创建的 VirtualList 组件
- 只渲染可见区域的消息

**涉及文件**:
- `src/components/RAGChat/index.tsx`

### 3.2 骨架屏添加

**问题**: GraphEditor 加载时缺少骨架屏

**优化方案**:
- 创建 `GraphSkeleton` 组件
- 添加加载状态展示

**涉及文件**:
- `src/components/GraphEditor/GraphSkeleton.tsx` (新建)
- `src/pages/GraphEditor.tsx`

### 3.3 MindMapNode 优化

**问题**: React.memo 的 props 比较不够精确

**优化方案**:
- 添加自定义比较函数
- 只在关键 props 变化时重渲染

**涉及文件**:
- `src/components/GraphEditor/MindMapNode.tsx`

### 3.4 错误处理统一

**问题**: 前端错误处理分散

**优化方案**:
- 创建 `errorService.ts` 统一处理
- 添加错误类型分类
- 统一错误提示样式

**涉及文件**:
- `src/services/errorService.ts` (新建)

3. **代码质量**: 组件拆分、API 模块化
4. **用户体验**: 加载状态优化、虚拟滚动
