# 知识星球文字标签遮挡问题改进方案

## 问题分析

当前实现使用 `Html` 组件配合 `occlude="raycast"` 来显示文字标签：

```tsx
<Html
  position={[0, baseSize + 5, 0]}
  center
  occlude="raycast"
  style={{ pointerEvents: 'none', whiteSpace: 'nowrap', zIndex: zIndex }}
>
```

**存在的问题：**
1. `occlude="raycast"` 的遮挡检测基于射线检测，可能不够精确
2. `zIndex` 动态计算方式复杂，且可能与实际 3D 空间关系不一致
3. HTML 元素与 3D 场景的融合不够自然

## 替代方案对比

### 方案1: 使用 Text 组件（推荐）
使用 drei 的 `Text` 组件直接在 3D 空间中渲染文本。

**优点：**
- 纯 3D 渲染，遮挡关系完全由深度缓冲自动处理
- GPU 加速，性能更好
- 与 3D 场景融合自然

**缺点：**
- 需要加载字体文件
- 样式不如 HTML 丰富

### 方案2: 使用 Sprite + CanvasTexture
用 Canvas 绘制文本，然后作为纹理贴到 Sprite 上。

**优点：**
- 标签始终面向相机
- 遮挡关系正确
- 可以保持丰富的样式

**缺点：**
- 实现相对复杂
- 需要手动管理纹理更新

### 方案3: 使用 CSS2DRenderer
使用 drei 的 CSS2D 渲染器。

**优点：**
- 保持 HTML 样式
- 支持丰富的交互

**缺点：**
- 仍然可能有遮挡问题
- 需要额外配置

## 推荐方案：Text 组件

选择使用 `Text` 组件，原因：
1. 遮挡关系由 Three.js 的深度缓冲自动处理，无需手动计算
2. 性能更好
3. 实现简单，代码改动最小

## 实现计划

### 步骤1: 导入 Text 组件
从 `@react-three/drei` 导入 `Text` 组件。

### 步骤2: 替换 Html 为 Text
将 `PlanetNode` 组件中的 `Html` 替换为 `Text` 组件：
- 移除 `occlude` 和 `zIndex` 相关代码
- 使用 `Text` 的 `position`、`fontSize`、`color` 等属性
- 添加字体文件支持

### 步骤3: 移除不再需要的代码
- 移除 `nodeZIndices` 状态和相关计算逻辑
- 移除 `zIndex` prop

### 步骤4: 调整样式
- 调整文本位置、大小、颜色以匹配当前视觉效果
- 可能需要添加背景或描边来提高可读性

## 代码改动预览

```tsx
// 导入
import { OrbitControls, Text, Stars, Line } from '@react-three/drei';

// PlanetNode 组件中替换 Html
<Text
  position={[0, baseSize + 5, 0]}
  fontSize={3}
  color={isDark ? '#ffffff' : '#1e293b'}
  anchorX="center"
  anchorY="bottom"
  outlineWidth={0.5}
  outlineColor={isDark ? '#000000' : '#ffffff'}
>
  {node.data.title}
</Text>
```

## 注意事项

1. `Text` 组件默认使用内置字体，如需中文字体支持，可能需要加载额外字体
2. 标签的 `tags` 显示需要单独处理，可以考虑用多个 `Text` 组件或简化显示
