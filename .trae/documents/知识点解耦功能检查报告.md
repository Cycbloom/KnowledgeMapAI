## ⚠️ 潜在问题

### 1. 旧数据兼容性
**问题**: 后端代码中仍保留了对旧 `nodes` 表的查询作为 fallback。

**位置**: `api/routes/nodes.ts` 第 280-296 行、第 418-461 行

**影响**: 
- 迁移完成后，旧表数据应不再存在
- fallback 代码增加了维护复杂度

**建议**: 
- 确认数据迁移完成后，移除 fallback 代码
- 或保留一段时间作为安全网

### 2. 联立视图编辑功能
**问题**: 规格要求"联立视图编辑时提示影响范围"，但当前实现仅支持查看。

**位置**: `src/pages/CombinedViewPage.tsx`

**现状**: 
- 节点点击可查看详情
- 未实现编辑功能

**建议**: 
- 如需编辑功能，需添加编辑模式和影响范围提示

### 3. 公共知识点更新通知
**问题**: 规格要求"公共知识点更新时，用户收到通知"，但当前未实现通知机制。

**现状**: 
- 后端记录了 `approved_at`、`approved_by` 等信息
- 未实现主动通知用户的功能

**建议**: 
- 可使用 WebSocket 或轮询实现通知
- 或在用户访问图谱时显示提示

### 4. 管理员审核界面
**问题**: 后端 API 已实现，但前端可能缺少专门的管理员审核页面。

**检查**: 需确认是否有管理员审核 UI
