# 顶部 Header 优化计划

## 最终方案

Header 分为三部分：

| 左侧 | 中间 | 右侧 |
|------|------|------|
| 面包屑导航 | 问候语 + 学习进度 | SSE状态 + 帮助 + 用户头像 |

### 示例布局

```
首页 > 我的知识图谱    |    下午好，小明 | 🔥 连续 7 天 | 📚 今日复习 12 张    |    [状态] [?] [头像]
```

## 实现步骤

### 步骤 1：创建面包屑组件
- 根据当前路由路径生成面包屑
- 支持点击跳转
- 样式与整体风格一致

### 步骤 2：创建问候与进度组件
- 根据时间段显示问候语（早上好/下午好/晚上好）
- 显示连续学习天数
- 显示今日复习卡片数
- 数据从现有 API 获取

### 步骤 3：修改 Layout.tsx
- Header 改为三栏布局（左-中-右）
- 左侧：面包屑导航
- 中间：问候与进度
- 右侧：保持现有内容

## 涉及文件

- `src/components/Layout.tsx` - 修改 header 布局
- `src/components/Breadcrumb.tsx` - 新建面包屑组件
- `src/components/HeaderGreeting.tsx` - 新建问候与进度组件
