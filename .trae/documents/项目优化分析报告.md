### 1.1 Three.js 组件优化 ([PlanetView.tsx](file:///d:/KnowledgeMap/src/three/PlanetView.tsx))

**问题分析:**
- `NODE_COLORS` 对象在每次渲染时创建新的 `THREE.Color` 实例
- `useFrame` 钩子每帧执行，包含距离计算和状态更新
- 缺少 Three.js 对象的内存清理

**优化建议:**
```typescript
// 优化前
const NODE_COLORS = {
  root: new THREE.Color('#FFD700'),
  // ...
};

// 优化后 - 移到组件外部，只创建一次
const NODE_COLORS = Object.freeze({
  root: new THREE.Color('#FFD700'),
  core: new THREE.Color('#FF8C00'),
  normal: new THREE.Color('#4A90D9'),
  leaf: new THREE.Color('#00CED1'),
  selected: new THREE.Color('#FF69B4'),
  hover: new THREE.Color('#98FB98')
});

// useFrame 优化 - 使用 ref 而非 state 避免重渲染
const scaleRef = useRef(1);
useFrame(() => {
  if (meshRef.current) {
    meshRef.current.rotation.y += 0.003;
  }
  // 只在需要时更新 scale
  const distance = camera.position.distanceTo(nodePos);
  const newScale = Math.max(0.3, Math.min(2, distance / 200));
  if (Math.abs(scaleRef.current - newScale) > 0.1) {
    scaleRef.current = newScale;
  }
});
```

**预期收益:** 减少 30-50% 的 Three.js 渲染开销

2. **实现视口裁剪:**
```typescript
// 只渲染视口内的节点
const visibleNodes = useMemo(() => {
  if (!layout) return [];
  const { x, y, k } = transformRef.current;
  const viewportBounds = {
    minX: -x / k - 100,
    maxX: (-x + containerSize.width) / k + 100,
    minY: -y / k - 100,
    maxY: (-y + containerSize.height) / k + 100,
  };
  
  return layout.nodes.filter(node => 
    node.x >= viewportBounds.minX &&
    node.x <= viewportBounds.maxX &&
    node.y >= viewportBounds.minY &&
    node.y <= viewportBounds.maxY
  );
}, [layout, transform, containerSize]);
```

3. **使用 requestAnimationFrame 节流:**
```typescript
const rafRef = useRef<number>();
const updateTransform = useCallback((newTransform: Transform) => {
  if (rafRef.current) cancelAnimationFrame(rafRef.current);
  rafRef.current = requestAnimationFrame(() => {
    transformRef.current = newTransform;
    updateTransformDOM(newTransform);
  });
}, []);
```

**预期收益:** 大型图谱 (>500 节点) 渲染性能提升 50-70%

### 2.1 AI 服务优化 ([aiService.ts](file:///d:/KnowledgeMap/api/services/ai/index.ts))

**问题分析:**
- AI 调用缺少超时控制
- 缺少请求去重
- 错误处理不够精细

**优化建议:**

1. **添加请求超时和重试:**
```typescript
const withTimeout = <T>(promise: Promise<T>, ms: number): Promise<T> => {
  return Promise.race([
    promise,
    new Promise<T>((_, reject) => 
      setTimeout(() => reject(new Error('AI request timeout')), ms)
    ),
  ]);
};

// 使用
const completion = await withTimeout(
  provider.client.chat.completions.create({...}),
  30000 // 30秒超时
);
```

2. **实现请求去重:**
```typescript
const pendingRequests = new Map<string, Promise<any>>();

const dedupedRequest = async <T>(key: string, fn: () => Promise<T>): Promise<T> => {
  const pending = pendingRequests.get(key);
  if (pending) return pending;
  
  const promise = fn().finally(() => pendingRequests.delete(key));
  pendingRequests.set(key, promise);
  return promise;
};
```

### 2.3 数据库查询优化

**优化建议:**

```typescript
// middleware/queryLogger.ts
export const queryLogger = (req, res, next) => {
  const start = Date.now();
  res.on('finish', () => {
    const duration = Date.now() - start;
    if (duration > 1000) {
      logger.warn(`Slow query: ${req.path} took ${duration}ms`);
    }
  });
  next();
};
```

```sql
-- 添加复合索引
CREATE INDEX idx_nodes_graph_deleted ON nodes(graph_id, deleted_at) 
  WHERE deleted_at IS NULL;

-- 使用 CTE 优化复杂查询
WITH graph_nodes AS (
  SELECT * FROM nodes WHERE graph_id = $1 AND deleted_at IS NULL
)
SELECT n.*, e.id as edge_id, e.target_node_id
FROM graph_nodes n
LEFT JOIN edges e ON e.source_node_id = n.id;
```

```typescript
// utils/errorHandler.ts
export class AppError extends Error {
  constructor(
    message: string,
    public code: string,
    public statusCode: number = 500,
    public context?: Record<string, unknown>
  ) {
    super(message);
    this.name = 'AppError';
  }
}

export const handleApiError = (error: unknown) => {
  if (error instanceof AppError) {
    return { message: error.message, code: error.code };
  }
  if (axios.isAxiosError(error)) {
    return { message: error.response?.data?.message || '网络错误', code: 'NETWORK_ERROR' };
  }
  return { message: '未知错误', code: 'UNKNOWN' };
};
```
