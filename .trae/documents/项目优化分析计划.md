## 修复计划

### 第一阶段: React Hooks 错误修复

| 文件 | 问题 | 修复方案 |
|------|------|----------|
| GraphEditor.tsx | 条件性 hooks 调用 | 重构组件结构，确保 hooks 在顶层调用 |
| NodeDetailSidebar.tsx | early return 后的 hooks | 将 early return 移到 hooks 调用之后 |
| MindMapCanvas.tsx | 渲染期访问 refs | 使用 useEffect 或回调 ref |
| RAGChat/index.tsx | 渲染期创建组件 | 将组件定义移到组件外部 |

### 第二阶段: 变量声明问题修复

| 文件 | 问题 | 修复方案 |
|------|------|----------|
| useErrorHandler.ts | 变量提升问题 | 重新组织变量声明顺序 |
| useError.ts | 变量提升问题 | 重新组织变量声明顺序 |
| serviceWorker.ts | 变量提升问题 | 重新组织变量声明顺序 |

### 第三阶段: 其他错误修复

| 文件 | 问题 | 修复方案 |
|------|------|----------|
| performanceUtils.ts | case 语句声明 | 使用块语句包裹 case 内容 |
| markdownParser.ts | 无用转义 | 移除不必要的转义字符 |
| timelineLayout.ts | 无效表达式 | 修复表达式语句 |

| ai/providers/*.ts | Function 类型 | 使用具体函数类型 |
