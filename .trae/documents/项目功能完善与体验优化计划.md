经过对项目的全面分析，我发现虽然核心功能（图谱编辑、AI 生成、学习模式）已经相当完善，但仍存在一些影响生产环境可用性和用户体验的关键缺陷。

我建议优先完成以下两项改进：

### 1. 修复 PDF 导出的跨平台字体问题 (高优先级)
**问题现状**：
目前后端 `api/routes/data.ts` 中的 PDF 生成逻辑硬编码了 Windows 系统字体路径（如 `C:\Windows\Fonts\simhei.ttf`）。
**风险**：
如果项目部署到 Linux 服务器或 Docker 容器中，由于缺少这些字体文件，导出的 PDF 中文内容将显示为乱码或方框。
**实施计划**：
- 下载开源中文字体（Noto Sans SC 简化版）到项目资源目录。
- 重构 PDF 生成代码，使其优先加载项目内置字体，确保在任何操作系统下都能完美输出中文 PDF。

### 2. 增强 AI 模拟模式的视觉提示 (中优先级)
**问题现状**：
当用户未配置 API Key 时，系统会自动降级为“模拟模式”（返回 Mock 数据）。目前仅在进入编辑器时显示一个临时的 Toast 提示，用户很容易错过，导致误以为系统出 Bug 或数据不准确。
**实施计划**：
- 在图谱编辑器顶部的工具栏 (`GraphToolbar`) 中添加一个常驻的“演示模式”或“未配置 AI”徽章。
- 点击该徽章可直接引导用户跳转到设置页面配置 API Key。

这两个改进将显著提升项目的稳定性和用户体验。是否同意执行？
