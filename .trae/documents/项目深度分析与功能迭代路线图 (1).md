# 项目深度分析与功能迭代路线图

基于对代码库的全面扫描与逻辑梳理，我为您制定了以下系统分析报告与功能迭代计划。

## 1. 系统深度分析 (System Analysis)

### 1.1 项目架构与技术栈
本项目采用 **前台-中台-后台** 分层架构，实现了知识图谱的生成、管理与内化闭环。
*   **前端 (Frontend)**: React 18 + Vite + TypeScript。核心是 `Graph3D` (Three.js/Fiber) 负责高性能 3D 渲染，`GraphEditor` 负责交互。状态管理使用 Zustand。
*   **后端 (Backend)**: Node.js + Express。采用 Controller-Service 分层模式。
*   **数据层 (Data Layer)**: Supabase (PostgreSQL) + PgVector (向量搜索) + Redis (缓存/限流)。
*   **AI 服务**: 采用工厂模式 (`ai/factory.ts`) 集成多模型 (DeepSeek, Aliyun, Volcengine)，实现了文本生成图谱 (Text-to-Graph) 和 RAG 问答。

### 1.2 核心业务逻辑
1.  **知识图谱**: 节点 (Nodes) 与边 (Edges) 的增删改查，支持 3D 力导向布局。
2.  **智能学习**: 集成 `ts-fsrs` 算法实现间隔重复 (Spaced Repetition) 复习系统。
3.  **AI 增强**: 
    *   **生成**: 输入文本/文件自动提取知识结构。
    *   **搜索**: 混合检索 (关键词 + 向量语义)，支持 RAG (检索增强生成) 问答。

## 2. 现状诊断：技术债务与功能空白

### 2.1 关键技术债务 (Technical Debt)
| 模块 | 问题描述 | 风险等级 | 影响分析 |
| :--- | :--- | :--- | :--- |
| **任务队列** | 当前使用 `setInterval` 轮询数据库处理异步任务 (`TaskProcessor`)。 | **High** | 无法横向扩展，存在竞态条件，无重试机制，AI 服务波动易导致任务丢失。 |
| **认证鉴权** | 仅校验 Token 有效性，缺乏 Refresh Token 机制。 | **Medium** | Token 过期后用户被强制登出，可能打断编辑流，体验较差。 |
| **代码质量** | `api/routes/study.ts` 中保留了低效的调试查询代码；前端 `GraphRenderables` 存在“异步点击”临时修复。 | **Medium** | 随着数据量增长，低效查询将严重拖累数据库性能。 |
| **移动端** | 3D 视图在移动端交互困难 (缩放/选中)。 | **Medium** | 限制了用户随时随地复习的使用场景。 |

### 2.2 功能空白 (Feature Gaps)
*   **数据主权**: 缺乏通用的导出功能 (Markdown/Obsidian, JSON)，用户数据被锁定。
*   **协作能力**: 仅支持单人模式，无分享或团队协作功能。
*   **深度搜索**: 后端已实现语义搜索接口，但前端尚未集成，用户无法体验“概念搜索”。

## 3. 功能迭代路线图 (Execution Roadmap)

建议分为三个阶段推进，优先解决稳定性问题，再扩展智能与生态功能。

### 阶段一：稳固基础 (Stability & Foundation) - P0
> **目标**: 消除高危技术债务，确保系统稳定可靠。

1.  **任务队列重构 (Backlog Priority: Highest)**
    *   **任务**: 引入 Redis + BullMQ 替换现有的轮询机制。
    *   **价值**: 提升 AI 任务 (如批量生成图谱) 的成功率和并发处理能力。
2.  **认证机制完善**
    *   **任务**: 实现 Access Token + Refresh Token 双令牌机制，前端增加 401 自动刷新拦截器。
    *   **价值**: 实现“无感登录”，保护用户编辑成果。
3.  **数据导出功能**
    *   **任务**: 实现图谱导出为 Markdown (兼容 Obsidian 链接格式) 和 JSON 备份。
    *   **价值**: 解除用户对数据锁定的担忧，增强工具互通性。

### 阶段二：智能增强 (Intelligence & Experience) - P1
> **目标**: 释放 AI 潜力，提升移动端体验。

1.  **语义搜索全栈集成**
    *   **任务**: 对接后端 `/api/search?type=semantic` 接口，在前端实现自然语言问答 (RAG) UI。
    *   **价值**: 让用户能搜索“概念”而非仅仅“关键词”，提升知识检索效率。
2.  **移动端复习模式**
    *   **任务**: 开发移动端专用视图，自动屏蔽 3D 画布，仅展示复习卡片 (Flashcards) 和列表。
    *   **价值**: 激活碎片化学习场景。
3.  **相关节点推荐**
    *   **任务**: 利用 PgVector 计算节点相似度，在侧边栏推荐“潜在关联”节点。
    *   **价值**: 帮助用户发现知识盲区，自动织网。

### 阶段三：协作与生态 (Collaboration) - P2
> **目标**: 从个人工具迈向团队知识库。

1.  **图谱公开分享**
    *   **任务**: 生成只读分享链接 (Public URL)，允许未登录用户查看 3D 视图。
2.  **性能优化 (LOD)**
    *   **任务**: 优化 3D 渲染的 Level of Detail (LOD) 策略，支持万级节点流畅渲染。
