# 领域图谱批量生成对话框 - 从现有图谱扩展添加领域选择

## 问题描述

当前 `DomainGraphGenerator` 组件的"从现有图谱扩展"模式下，用户只能选择现有图谱，无法指定领域方向。用户希望在扩展时能够选择/指定一个领域，以便 AI 能够更有针对性地推荐相关图谱。

   - 第 149-154 行：调用 `expandDomain` API

### 3. 前端 API 修改

```typescript
// src/services/api/graphs.ts
expandDomain: (graphIds: string[], count: number = 10, domain?: string): Promise<DomainExpansionResult> => 
  request('/graphs/domain/expand', { 
    method: 'POST', 
    body: JSON.stringify({ graph_ids: graphIds, count, domain }) 
  }),
```
