# 领域图谱批量生成对话框 - 修复"从现有图谱扩展"无法选择图谱的问题

## 问题描述

在 `DomainGraphGenerator` 组件的"从现有图谱扩展"模式下，用户无法选择图谱。这是因为组件内部使用了不存在的 `window.api` 对象来调用 API。

## 问题根因

**文件**：[DomainGraphGenerator.tsx](file:///d:/KnowledgeMap/src/components/GraphMap/DomainGraphGenerator.tsx)

### 问题代码 1：第 107-119 行

```typescript
const loadSourceGraphs = async () => {
  try {
    setIsLoadingSourceGraphs(true);
    const result = await (window as any).api.graphs.getMap();  // ❌ window.api 不存在
    if (result?.graphs) {
      setSourceGraphs(result.graphs);
    }
  } catch (err) {
    console.error('Failed to load source graphs:', err);
  } finally {
    setIsLoadingSourceGraphs(false);
  }
};
```

### 问题代码 2：第 149-154 行

```typescript
} else {
  result = await (window as any).api.graphs.expandDomain(  // ❌ window.api 不存在
    Array.from(selectedSourceGraphs),
    graphCount
  );
}
```

## 解决方案

修改 `DomainGraphGenerator` 组件，通过 props 传入必要的 API 回调函数，而不是直接使用 `window.api`。

## 实现计划

### 步骤 1：修改组件 Props 接口

**文件**：`src/components/GraphMap/DomainGraphGenerator.tsx`

添加两个新的 props：
- `onLoadSourceGraphs`: 加载现有图谱列表的回调
- `onExpandDomain`: 从现有图谱扩展的回调

```typescript
interface DomainGraphGeneratorProps {
  isOpen: boolean;
  onClose: () => void;
  onGenerateDomain: (domain: string, count: number) => Promise<{ graphs: RecommendedGraph[]; relations: GraphRelation[] }>;
  onBatchCreate: (graphs: RecommendedGraph[], relations: GraphRelation[], domain?: string) => Promise<CreatedGraph[]>;
  onInitializeGraphs?: (graphIds: string[]) => Promise<void>;
  onLoadSourceGraphs?: () => Promise<{ graphs: SourceGraph[] }>;  // 新增
  onExpandDomain?: (graphIds: string[], count: number) => Promise<{ recommendations: RecommendedGraph[]; relations: GraphRelation[] }>;  // 新增
}
```

### 步骤 2：修改组件内部实现

**文件**：`src/components/GraphMap/DomainGraphGenerator.tsx`

修改 `loadSourceGraphs` 和 `handleGenerate` 函数，使用 props 传入的回调：

```typescript
const loadSourceGraphs = async () => {
  if (!onLoadSourceGraphs) return;
  try {
    setIsLoadingSourceGraphs(true);
    const result = await onLoadSourceGraphs();
    if (result?.graphs) {
      setSourceGraphs(result.graphs);
    }
  } catch (err) {
    console.error('Failed to load source graphs:', err);
  } finally {
    setIsLoadingSourceGraphs(false);
  }
};

// handleGenerate 中
} else {
  if (!onExpandDomain) return;
  result = await onExpandDomain(
    Array.from(selectedSourceGraphs),
    graphCount
  );
}
```

### 步骤 3：修改调用方传入回调

**文件**：`src/pages/GraphMap.tsx`

在 `DomainGraphGenerator` 组件调用处添加新的 props：

```tsx
<DomainGraphGenerator
  isOpen={isDomainGeneratorOpen}
  onClose={() => setIsDomainGeneratorOpen(false)}
  onGenerateDomain={async (domain: string, count: number) => {
    const result = await api.graphs.analyzeDomain(domain, count);
    return {
      graphs: result.recommendations,
      relations: result.relations,
    };
  }}
  onBatchCreate={async (graphs, relations, domain?: string) => {
    // ... 现有代码
  }}
  onInitializeGraphs={async (graphIds: string[]) => {
    // ... 现有代码
  }}
  onLoadSourceGraphs={async () => {
    const result = await api.graphs.getMap();
    return { graphs: result.graphs };
  }}
  onExpandDomain={async (graphIds: string[], count: number) => {
    const result = await api.graphs.expandDomain(graphIds, count);
    return {
      recommendations: result.recommendations,
      relations: result.relations,
    };
  }}
/>
```
