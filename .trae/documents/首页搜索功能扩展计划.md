# 首页搜索功能扩展计划

## 目标

将 Dashboard 首页的搜索功能从仅支持图谱搜索扩展为同时支持图谱和节点搜索，并支持语义搜索。

## 当前状态分析

### 现有实现

1. **Dashboard 搜索**（`src/pages/Dashboard.tsx`）
   - 纯前端过滤，基于图谱标题和描述的模糊匹配
   - 不调用后端 API
   - 仅支持图谱搜索

2. **后端搜索 API**（`api/routes/search.ts`）
   - `GET /search?q=关键词` - 关键词搜索
   - `GET /search?q=关键词&type=semantic` - 语义搜索
   - 已支持图谱和节点搜索

3. **语义搜索**（`api/services/searchService.ts`）
   - 基于向量相似度
   - 使用 `match_nodes` RPC 函数
   - 支持 RAG 生成答案

### 需要改进

- Dashboard 搜索框需要调用后端 API
- 需要展示图谱和节点两种类型的搜索结果
- 需要支持语义搜索模式

## 实现方案

### 1. 前端搜索 API 封装

**文件**: `src/services/api/search.ts`（新建）

```typescript
export interface SearchResult {
  graphs: Array<{
    id: string;
    title: string;
    description?: string;
    updated_at: string;
  }>;
  nodes: Array<{
    knowledge_point_id: string;
    graph_id: string;
    title: string;
    content?: string;
    graph_title: string;
    similarity?: number;
  }>;
  answer?: string; // 语义搜索时的 AI 回答
}

export const searchApi = {
  search: (query: string): Promise<SearchResult> => 
    request(`/search?q=${encodeURIComponent(query)}`),
  
  semanticSearch: (query: string): Promise<SearchResult> => 
    request(`/search?q=${encodeURIComponent(query)}&type=semantic`),
};
```

### 2. 搜索结果展示组件

**文件**: `src/components/SearchResults.tsx`（新建）

功能：
- 分组展示图谱和节点结果
- 图谱结果：显示标题、描述、更新时间
- 节点结果：显示标题、内容摘要、所属图谱、相似度
- 语义搜索时显示 AI 生成的答案
- 点击结果跳转到对应页面

### 3. Dashboard 搜索框改造

**文件**: `src/pages/Dashboard.tsx`

改动：
- 添加搜索模式切换（关键词/语义）
- 输入防抖后调用后端 API
- 展示搜索结果弹窗/下拉
- 保留原有的标签过滤功能

### 4. 搜索 Hook

**文件**: `src/hooks/useSearch.ts`（新建）

功能：
- 防抖搜索
- 支持关键词和语义两种模式
- 管理搜索状态（loading、results、error）

## 风险与注意事项

1. **性能考虑**：语义搜索需要生成向量，响应时间可能较长
2. **防抖时间**：建议 300-500ms，避免频繁 API 调用
3. **空结果处理**：需要友好的空状态提示
4. **移动端适配**：搜索结果弹窗需要适配小屏幕
