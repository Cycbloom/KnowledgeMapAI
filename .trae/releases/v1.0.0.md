# Release v1.0.0

**发布日期**: 2025-03-15

## 版本概述

这是 KnowledgeMap 项目的第一个正式发布版本，包含了核心的知识图谱编辑、学习管理、任务调度和 AI 辅助功能。

## 主要功能

### 1. 知识图谱编辑器
- 节点创建、编辑、删除
- 拖拽布局和自动排列
- 多种视图模式（思维导图、树形、时间线）
- 图谱导出（PNG、PDF、JSON）

### 2. 协作功能
- 多用户协作编辑
- 角色权限管理（Owner/Editor/Viewer）
- 分享邀请链接

### 3. 学习系统
- 学习卡片生成和复习
- FSRS 间隔重复算法
- 学习路径管理
- 测验系统

### 4. 任务调度
- 任务创建和管理
- 任务依赖关系
- 番茄钟专注计时
- 成就系统

### 5. AI 功能
- AI 对话助手
- 内容生成
- RAG 知识库问答
- 文本转图谱

## 技术栈

- **前端**: React 18, TypeScript, Vite, Tailwind CSS, React Query
- **后端**: Express, TypeScript
- **数据库**: Supabase (PostgreSQL)
- **部署**: Vercel
- **测试**: Vitest, Playwright

## 如何使用此版本

```bash
# 克隆仓库
git clone <repository-url>
cd KnowledgeMap

# 切换到 v1.0.0 标签
git checkout v1.0.0

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入必要的配置

# 启动开发服务器
npm run dev
```
