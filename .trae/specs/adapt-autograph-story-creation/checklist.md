# Checklist - AI 图谱生成器适配故事创作模板

## 前端 UI
- [x] 选择"小说/故事创作"模板后，通用风格选择区域被隐藏
- [x] 选择"小说/故事创作"模板后，参考来源区域被隐藏
- [x] 故事专属配置区域正确显示（题材下拉、核心冲突、角色提示）
- [x] 故事题材下拉包含：奇幻/科幻/悬疑/言情/历史/都市/武侠/其他
- [x] 从故事创作切换到其他模板时，故事专属配置被清除，通用配置恢复
- [x] 从其他模板切换到故事创作时，通用配置被清除，故事专属配置初始化

## 生成流程
- [x] 点击"开始生成"时，故事专属参数（genre、coreConflict、characterHints）被正确传递给后端
- [x] 后端收到 story_creation 请求时走专属生成分支（非通用 AI 生成路径）
- [x] AI 生成的结果包含故事结构骨架节点（Story → Act → Sequence）
- [x] 如提供角色提示，AI 生成的结果包含角色节点
- [x] 未提供角色提示时，仍能正常生成结构骨架

## 保存与跳转
- [x] 保存 story_creation 图谱时 template_type 正确设置为 "story_creation"
- [x] 保存后打开图谱时正确进入 StoryEditor（非通用图谱编辑器）
- [x] StoryEditor 中能看到 AI 生成的初始结构骨架

## i18n
- [x] 故事创作专属配置的中文标签正确显示
- [x] 故事创作专属配置的英文标签正确显示
- [x] 各题材选项的中英文翻译正确

## 代码质量
- [x] `npm run check` 通过
- [x] `npm run lint` 通过
