# Checklist

## 核心功能验证

- [x] 无限扩展功能：从有领域的图谱扩展时，新图谱正确关联到源图谱的领域
- [x] 无限扩展功能：源图谱无领域时，新图谱不强制设置领域
- [x] 批量创建功能：批量创建图谱时，所有图谱正确关联到指定领域
- [x] 批量创建功能：支持通过领域ID（UUID）创建关联

## AI Prompt验证

- [x] `infinite_graph_expansion` prompt 包含领域上下文变量

- [x] 领域上下文正确传递给AI模型

## 数据库验证

- [x] 新创建的图谱在 `knowledge_graphs.domain` 字段有正确的值
- [x] 新创建的图谱在 `graph_domains` 表中有正确的关联记录
- [x] 关联记录的 `is_primary` 字段正确设置

## 数据迁移验证

- [x] 已有图谱的领域关联正确迁移

- [x] 迁移脚本可重复执行（幂等性）
