# Architecture Innovation Checklist

## Phase 1: 基础架构升级

### RAG 流水线架构升级
- [ ] `ragService.ts` 中的余弦相似度计算已替换为 pgvector 数据库函数调用
- [ ] 文档分块服务（ChunkingService）已实现，支持按段落/语义/固定长度分块
- [ ] Cross-Encoder 重排序已集成，RAG 检索结果经过二次排序
- [ ] 动态上下文窗口管理已实现，超 token 限制时自动裁剪低相关性内容
- [ ] `document_chunks` 表已创建并添加 HNSW 向量索引
- [ ] RAG 流水线集成测试通过，搜索质量有可量化的提升

### Agent 系统升级
- [ ] `SessionManager` 已迁移到 Supabase 数据库持久化，服务重启后会话可恢复
- [ ] `ToolRegistry` 支持动态注册/注销工具，与插件生命周期联动
- [ ] Agent 最大迭代次数从 `app_settings` 读取，不再硬编码
- [ ] Agent 会话并发控制已实现，同一会话并发请求不会导致状态混乱

### SM2 清理
- [ ] `sm2Service.ts` 已移除
- [ ] `knowledge_review_tasks` 数据库表及相关迁移已移除
- [ ] 所有 SM2 相关引用和导入已清理
