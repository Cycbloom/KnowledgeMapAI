## 测试策略建议

### 1. 测试金字塔结构
```
        /\
       /E2E\       (3 个文件，需要增加)
      /------\
     /Integration\   (0 个文件，需要补充)
    /------------\
   /   Unit Tests  \  (9 个文件，需要大幅增加)
  /----------------\
```

### 2. 推荐工具和框架
- **单元测试**: Vitest + React Testing Library
- **E2E 测试**: Playwright
- **Mocking**: MSW (Mock Service Worker)
- **Coverage**: c8 + Istanbul

### 3. 测试数据策略
- 使用测试数据库 (Supabase 本地实例)
- 准备测试数据种子
- 每个测试独立运行，不共享状态
