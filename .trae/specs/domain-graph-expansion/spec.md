# 领域图谱扩展功能 - 产品需求文档

## Overview
- **Summary**: 增强现有的领域图谱批量生成功能，支持从现有图谱出发智能扩展新的相关知识图谱，同时确保不与现有图谱重复。
- **Purpose**: 帮助用户从已有知识图谱出发，发现和创建更多相关的知识图谱，构建完整的知识体系，避免重复创建。
- **Target Users**: KnowledgeMap 的所有用户，特别是希望系统地构建知识体系的学习者。

## Goals
- 支持从选中的现有图谱出发，智能扩展新的相关图谱
- 增强去重检测，确保新生成的图谱不与现有图谱重复
- 提供友好的用户界面，让用户可以选择要扩展的图谱
- 保持与现有批量生成功能的一致性体验

## Non-Goals (Out of Scope)
- 不修改现有的从零开始生成领域图谱的功能
- 不修改图谱内部节点的生成逻辑
- 不添加跨用户的图谱推荐功能

## Background & Context
- **现有功能**: 已经有 `DomainGraphGenerator` 组件，可以从零开始输入一个领域主题，AI 生成推荐的图谱列表并批量创建
- **去重逻辑**: 现有的 API 已经有基本的去重检测，通过检查图谱标题是否已存在来避免重复
- **增强需求**: 用户希望能够从已有的图谱出发，让 AI 推荐更多相关的图谱来扩展知识体系

## Functional Requirements
- **FR-1**: 在 DomainGraphGenerator 中添加"从现有图谱扩展"模式
- **FR-2**: 支持选择一个或多个现有图谱作为扩展起点
- **FR-3**: AI 基于选中的图谱推荐相关的新图谱
- **FR-4**: 增强去重检测，不仅检查标题，还考虑内容相似度
- **FR-5**: 在推荐列表中清晰标识哪些图谱已存在，哪些是新推荐的
- **FR-6**: 允许用户选择要创建的新图谱（跳过已存在的）

## Non-Functional Requirements
- **NFR-1**: 扩展推荐的响应时间应在 60 秒内完成
- **NFR-2**: 去重检测的准确率应达到 95% 以上
- **NFR-3**: UI 响应流畅，无明显卡顿

## Constraints
- **Technical**: 使用现有的 AI 服务和 Supabase 数据库
- **Business**: 保持与现有功能的用户体验一致性
- **Dependencies**: 依赖现有的 graphService、aiService 和 DomainGraphGenerator 组件

## Assumptions
- 用户已经有一些现有的知识图谱
- AI 能够基于现有图谱的标题和描述推荐相关主题
- 用户会定期使用这个功能来扩展他们的知识体系

## Acceptance Criteria

### AC-1: 从现有图谱扩展模式
- **Given**: 用户打开 DomainGraphGenerator
- **When**: 用户选择"从现有图谱扩展"模式
- **Then**: 显示用户的现有图谱列表供选择
- **Verification**: `programmatic`
- **Notes**: 列表应显示图谱标题、描述和节点数量

### AC-2: 选择扩展起点
- **Given**: 用户在"从现有图谱扩展"模式下
- **When**: 用户选择一个或多个图谱作为扩展起点
- **Then**: 系统记录选中的图谱并准备生成推荐
- **Verification**: `programmatic`
- **Notes**: 支持多选，最多 5 个图谱

### AC-3: AI 推荐相关图谱
- **Given**: 用户已选择扩展起点图谱
- **When**: 用户点击"生成推荐"
- **Then**: AI 基于选中的图谱生成相关的新图谱推荐列表
- **Verification**: `programmatic`
- **Notes**: 推荐应包含标题、描述、优先级和关系

### AC-4: 增强去重检测
- **Given**: AI 生成了推荐图谱列表
- **When**: 系统处理推荐列表
- **Then**: 系统检测并标识已存在的图谱（不仅通过标题，还通过内容相似度）
- **Verification**: `programmatic`
- **Notes**: 已存在的图谱应在 UI 中明确标识并默认不选中

### AC-5: 用户选择创建的图谱
- **Given**: 推荐列表已生成并去重
- **When**: 用户查看推荐列表
- **Then**: 用户可以选择要创建的新图谱（已存在的默认不选中）
- **Verification**: `human-judgment`
- **Notes**: UI 应清晰区分已存在和新推荐的图谱

### AC-6: 批量创建新图谱
- **Given**: 用户已选择要创建的新图谱
- **When**: 用户点击"创建图谱"
- **Then**: 系统批量创建选中的新图谱并建立关系
- **Verification**: `programmatic`
- **Notes**: 创建完成后刷新图谱地图
