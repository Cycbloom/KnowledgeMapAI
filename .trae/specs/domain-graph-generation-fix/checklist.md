# Checklist

## 图谱关系创建

- [x] 批量创建图谱后，图谱之间的关系正确创建

- [x] 图谱地图上能看到连线
- [x] 连线颜色与关系类型匹配

- [x] 背景框正确包围同领域的所有图谱节点

- [x] 背景框显示图谱数量

- [x] 初始化任务创建成功

- [x] 知识点之间有连线（边）
- [x] 用户可在任务列表查看进度

- [x] 代码通过 lint 检查
