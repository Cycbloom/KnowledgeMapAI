# Checklist

## 图谱推荐优化

- [x] 图谱推荐 API 单次生成，不超时
- [x] 推荐结果只包含标题和描述，不包含知识点
- [x] 可以一次生成 10-30 个推荐
- [x] AI 请求在合理时间内完成（< 60秒）

## 批量创建分离

- [x] 批量创建只创建空图谱
- [x] 不自动生成知识点内容
- [x] 返回创建成功的图谱列表
- [x] domain 字段正确设置

## 分层初始化

- [x] 初始化分为三层：根节点 → 核心节点 → 子节点
- [x] 每层单独 AI 请求，不超时
- [x] 根节点生成 1 个
- [x] 核心节点生成 3-5 个
- [x] 子节点生成合理数量
- [x] 显示初始化进度

## 并行初始化

- [x] 支持并行初始化多个图谱
- [x] 每个图谱初始化独立进行
- [x] 显示整体进度

## 前端 UI

- [x] 两阶段流程清晰
- [x] 第一阶段显示推荐列表
- [x] 创建完成后询问是否初始化
- [x] 初始化时显示进度
