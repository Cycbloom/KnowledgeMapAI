# Checklist

## 骨干网络生成验证（第一阶段）

- [x] 骨干网络能根据研究主题正确生成
- [x] 骨干网络包含正确的大模块（研究背景、文献综述、研究方法、核心概念、应用领域、未来方向）
- [x] 每个模块只生成简要描述，不深入细节
- [x] 只生成 root 和 core 级别的节点
- [x] 不生成 sub、normal、leaf 级别的详细节点
- [x] 模块之间建立了基本关系连线
- [x] 每个模块显示"待完善"状态

## 后端功能验证（第二阶段）

- [x] 概念提取服务能正确解析文本内容
- [x] 概念提取服务能正确解析上传的文档文件（PDF、Word、Markdown）
- [x] 概念提取服务能正确抓取网页 URL 内容
- [x] AI 能正确识别并分类概念（方法、机制、操作、概念、技术、工具）
- [x] 概念能智能定位到正确的骨干模块
- [x] 相似度检测能准确识别相同概念
- [x] 相似度检测能准确识别相似概念
- [x] 概念聚合能正确提升节点等级
- [x] 来源文献信息能正确合并到节点属性
- [x] 关系推断能生成合理的概念关系
- [x] API 接口返回正确的数据结构

## 前端功能验证

- [x] 文献输入面板能正确显示在图谱编辑器中
- [x] 文本输入方式能正常工作
- [x] 文件上传方式能正常工作
- [x] URL 输入方式能正常工作
- [x] 处理进度能正确显示
- [x] 概念预览列表能正确显示提取结果
- [x] 相似度提示能正确显示
- [x] 概念类型徽章能正确显示不同类型
- [x] 概念将添加到的骨干模块能正确显示
- [x] 用户能选择性地添加概念
- [x] 用户能编辑概念后再添加
- [x] 确认后概念能正确添加到对应的骨干模块下
- [x] 节点来源数量徽章能正确显示
- [x] 节点视觉权重能随来源数量变化
- [x] 骨干模块状态能正确显示（待完善/已完善）
- [x] 骨干模块下的概念数量能正确显示

## 数据持久化验证

- [x] 节点 properties 能正确存储来源文献信息
- [x] 图谱 reference_books 能正确存储文献引用
- [x] 概念类型能正确存储在节点属性中
- [x] 来源数量能正确计算和存储
- [x] 骨干模块状态能正确存储

## 用户体验验证

- [x] 功能入口位置合理，易于发现
- [x] 两阶段工作流清晰，用户易于理解
- [x] 操作流程清晰，用户易于理解
- [x] 错误提示友好，易于理解
- [x] 加载状态清晰，用户知道正在处理
- [x] 预览界面信息完整，便于用户决策
- [x] 国际化文本正确显示

## 性能与稳定性验证

- [x] 大文本处理不会导致页面卡顿
- [x] 文件上传有大小限制提示
- [x] URL 抓取有超时处理
- [x] AI 调用有重试机制
- [x] 性能监控数据正确记录
