# 图谱列表视图切换功能 Spec

## Why
当前 Dashboard 页面仅提供卡片视图展示图谱列表，用户无法根据个人偏好选择不同的展示方式。添加列表视图可以：
1. 提供更紧凑的信息展示，方便快速浏览大量图谱
2. 在列表视图中显示更多详细信息（如创建时间、更新时间等）
3. 提升用户体验，满足不同使用场景的需求

## What Changes
- 在 Dashboard 页面添加视图切换按钮（卡片/列表）
- 实现列表视图组件，以表格形式展示图谱信息
- 列表视图显示更多字段：标题、描述、节点数、创建时间、更新时间、操作按钮
- 保存用户的视图偏好到 localStorage，下次访问时恢复

## Impact
- Affected specs: Dashboard 页面展示能力
- Affected code: `src/pages/Dashboard.tsx`

## ADDED Requirements

### Requirement: 视图切换功能
系统应提供卡片视图和列表视图两种展示方式，用户可以自由切换。

#### Scenario: 切换视图
- **WHEN** 用户点击视图切换按钮
- **THEN** 图谱列表以对应的视图方式展示

#### Scenario: 记住视图偏好
- **WHEN** 用户切换视图后刷新页面或重新访问
- **THEN** 系统恢复用户上次选择的视图方式

### Requirement: 列表视图展示
列表视图应以表格形式展示图谱信息，包含以下列：
- 标题
- 描述（可截断）
- 节点数
- 创建时间
- 更新时间
- 操作按钮（编辑、删除、收藏等）

#### Scenario: 列表视图展示
- **WHEN** 用户选择列表视图
- **THEN** 图谱以表格行形式展示，每行包含完整信息

#### Scenario: 列表视图响应式
- **WHEN** 在移动端使用列表视图
- **THEN** 表格自适应屏幕宽度，隐藏次要信息或改为卡片式列表

### Requirement: 卡片视图保持不变
现有的卡片视图功能应保持不变，仅添加切换能力。

#### Scenario: 卡片视图正常工作
- **WHEN** 用户选择卡片视图
- **THEN** 图谱以现有卡片网格形式展示
