# 任务调度器系统重构需求分析

## Why

当前任务调度器系统存在以下问题：

1. **视图单一**：目前只有看板视图（三层队列垂直排列），缺乏直观的队列可视化
2. **拖拽体验差**：同队列内任务排序功能不稳定，用户无法流畅地调整任务顺序
3. **缺乏队列感**：用户希望看到一个横向的"排队器"视图，更直观地展示任务在队列中的位置和顺序
4. **队列配置不灵活**：固定三层队列，无法根据用户需求调整

## What Changes

- **切换拖拽库**：从 @dnd-kit 切换到 react-beautiful-dnd，获得更好的拖拽体验
- **新增横向队列视图**：以横轴展示任务队列，类似排队器，任务之间用箭头连接
- **可配置队列系统**：支持 2-5 个自定义队列，用户可配置名称、颜色、时间片
- **优化视图切换**：Tab 标签页切换，支持多种视图模式

## Impact

- Affected specs: 任务调度器核心功能
- Affected code:
  - `src/pages/Scheduler.tsx` - 主页面重构
  - `src/components/Scheduler/QueueColumn.tsx` - 队列列组件重构
  - `src/components/Scheduler/TaskCard.tsx` - 任务卡片重构
  - 新增 `src/components/Scheduler/HorizontalQueueView.tsx` - 横向队列视图
  - 新增 `src/components/Scheduler/QueueSettings.tsx` - 队列配置组件
  - 修改 `supabase/migrations/00000000000000_initial_schema.sql` - 队列表结构
  - 修改 `src/services/api/scheduler.ts` - API 更新

## 技术决策

### 1. 拖拽实现方案

**选择：切换到 react-beautiful-dnd**

理由：

- 内置优秀的动画和插入指示器
- 成熟稳定，文档完善
- 更好的可访问性支持
- 社区活跃，问题解决方案丰富

### 2. 横向队列布局

**选择：垂直堆叠横向队列**

### 3. 任务顺序指示

**选择：箭头连接线**

任务卡片之间用箭头连接，明确表示执行顺序。

### 4. 视图切换方式

**选择：Tab 标签页**

顶部 Tab 切换，支持以下视图：

- 队列视图（横向队列）
- 看板视图（按状态）
- 列表视图（表格）
- 时间轴视图（按时间）

### 5. 任务卡片样式

**选择：固定宽度卡片**

卡片宽度固定（约 180px），内容过长时显示省略号，整齐划一。

### 6. 跨队列拖拽行为

**选择：直接拖拽到目标队列**

用户可以直接将任务拖拽到目标队列的指定位置，一步到位。

### 7. 空队列处理

**选择：显示空队列占位符**

显示空队列框架和"拖拽任务到此处"提示，保持界面一致性。

### 8. 队列配置系统

**选择：完全自定义队列**

| 配置项   | 说明                                 |
| -------- | ------------------------------------ |
| 队列数量 | 2-5 个，用户可调整                   |
| 队列名称 | 用户自定义，如"紧急"、"重要"、"待办" |
| 队列颜色 | 预设颜色选择器                       |
| 时间片   | 用户自定义分钟数                     |
| 默认配置 | 新用户默认 3 个队列                  |

### 9. 删除队列时数据处理

**选择：自动迁移到相邻队列**

删除队列时，该队列的任务自动移动到相邻队列（优先向低优先级迁移）。

## ADDED Requirements

### Requirement: 横向队列视图

系统 SHALL 提供横向队列视图，以排队器的形式展示任务。

#### Scenario: 横向队列展示

- **WHEN** 用户选择"队列视图"Tab
- **THEN** 系统应以横轴展示所有队列
- **AND** 每个队列中的任务从左到右按执行顺序排列
- **AND** 任务之间用箭头连接表示顺序关系
- **AND** 空队列显示占位符和提示文字

#### Scenario: 横向拖拽排序

- **WHEN** 用户在横向队列中拖拽任务
- **THEN** 系统应显示插入点指示器
- **AND** 任务应平滑移动到新位置
- **AND** 箭头连接线应实时更新

#### Scenario: 跨队列横向拖拽

- **WHEN** 用户将任务从一个横向队列拖拽到另一个队列
- **THEN** 任务应从源队列消失
- **AND** 任务应出现在目标队列的指定位置
- **AND** API 应正确更新任务的 queue_level 和 position

### Requirement: 可配置队列系统

系统 SHALL 支持用户自定义队列配置。

#### Scenario: 查看队列配置

- **WHEN** 用户点击队列的"配置"按钮
- **THEN** 系统应显示队列配置面板
- **AND** 显示队列名称、颜色、时间片等设置

#### Scenario: 修改队列配置

- **WHEN** 用户修改队列名称、颜色或时间片
- **THEN** 系统应实时预览变更
- **AND** 保存后立即生效

#### Scenario: 添加新队列

- **WHEN** 用户点击"添加队列"按钮且当前队列数 < 5
- **THEN** 系统应在最低优先级队列下方添加新队列
- **AND** 新队列应有默认配置

#### Scenario: 删除队列

- **WHEN** 用户删除一个队列且当前队列数 > 2
- **THEN** 该队列的任务应自动迁移到相邻队列
- **AND** 系统应显示迁移确认提示
- **AND** 队列配置应更新

#### Scenario: 队列数量限制

- **WHEN** 用户尝试添加第 6 个队列
- **THEN** 系统应显示错误提示"最多支持 5 个队列"
- **WHEN** 用户尝试删除队列只剩 1 个
- **THEN** 系统应显示错误提示"至少需要 2 个队列"

### Requirement: 拖拽体验优化

系统 SHALL 提供流畅、准确的拖拽交互体验（基于 react-beautiful-dnd）。

#### Scenario: 插入点指示

- **WHEN** 用户拖拽任务在队列中移动
- **THEN** 系统应显示明确的插入线指示器
- **AND** 插入线应跟随鼠标位置实时更新
- **AND** 插入线应有明显的视觉区分

#### Scenario: 拖拽动画

- **WHEN** 用户拖拽任务
- **THEN** 任务卡片应有轻微的抬起和阴影效果
- **AND** 其他任务应平滑让出空间
- **AND** 放置时有平滑的落位动画

#### Scenario: 拖拽取消

- **WHEN** 用户开始拖拽但未放置到有效位置
- **THEN** 任务应平滑返回原位置
- **AND** 不应触发任何 API 调用

### Requirement: 视图切换

系统 SHALL 提供 Tab 标签页切换不同视图。

#### Scenario: 视图切换

- **WHEN** 用户点击视图 Tab
- **THEN** 系统应平滑切换到目标视图
- **AND** 当前选中的任务状态应保持
- **AND** 视图切换应有过渡动画

#### Scenario: 视图状态保持

- **WHEN** 用户在某个视图中操作后切换到其他视图
- **THEN** 切换回来时应保持之前的操作结果
- **AND** 滚动位置应保持

## MODIFIED Requirements

### Requirement: 数据库结构调整

现有 scheduled_tasks 表 SHALL 支持动态队列。

#### 原有结构

```sql
queue_level INTEGER NOT NULL DEFAULT 2  -- 固定 0, 1, 2
```

#### 新增结构

```sql
queue_id UUID REFERENCES queues(id)  -- 关联到队列表
position INTEGER NOT NULL DEFAULT 0
```

#### 新增队列表

```sql
CREATE TABLE queues (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  name TEXT NOT NULL,
  color TEXT NOT NULL DEFAULT 'blue',
  time_slice INTEGER NOT NULL DEFAULT 30,
  priority INTEGER NOT NULL,  -- 越小优先级越高
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ
);
```

## 数据迁移计划

### Phase 1: 数据库迁移

1. 创建 queues 表
2. 为每个现有用户创建默认 3 个队列
3. 将 scheduled_tasks.queue_level 迁移到 queue_id
4. 删除 queue_level 字段

### Phase 2: API 更新

1. 新增队列 CRUD API
2. 修改任务 API 支持 queue_id
3. 保持向后兼容（过渡期）

### Phase 3: 前端重构

1. 安装 react-beautiful-dnd
2. 重构拖拽组件
3. 实现横向队列视图
4. 实现队列配置 UI
