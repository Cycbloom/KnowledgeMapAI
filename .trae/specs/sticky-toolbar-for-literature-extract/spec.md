# 固定顶部工具栏 Spec

## Why

当前文献提取面板缺少统一的操作入口：
1. **提取前**：没有快速操作入口，用户需要滚动到"开始提取"按钮
2. **提取后**：工具栏混在状态信息中，不够醒目且不固定
3. **滚动体验差**：长列表时操作按钮被推到底部，需要滚回才能操作

需要一个**固定在顶部的统一工具栏**，提供常用操作的快速访问。

## What Changes

### 新增功能
1. **固定顶部工具栏组件**
   - 始终显示在面板最顶部
   - 使用 `sticky` 定位，滚动时保持可见
   - 根据当前阶段（输入/结果）动态显示不同按钮组

2. **输入阶段工具栏**
   - 📋 从剪贴板粘贴
   - ⚙️ 高级选项快捷开关
   - 📖 使用帮助/提示
   - ❌ 关闭面板

3. **结果阶段工具栏**
   - ✅ 保存到图谱
   - 🔄 重置（清空重新开始）
   - 📊 切换视图（查看结果/收起）
   - 📥 导出数据（JSON/CSV）
   - 📋 复制到剪贴板
   - ❌ 关闭面板

4. **通用功能**
   - 工具栏背景模糊效果（glass morphism）
   - 按钮分组显示（用分隔线区分）
   - 移动端适配（只显示图标）
   - 悬停提示（title 属性）

### UI 布局

```
┌─────────────────────────────────────────────────────┐ ← sticky top
│ [📋粘贴] [⚙️设置] [❓帮助]              [×关闭]    │ ← 输入阶段
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐ ← sticky top
│ [📊查看] [🔄重置] [📥导出] [📋复制] [✅保存] [×关闭] │ ← 结果阶段
├─────────────────────────────────────────────────────┤
│ ✅ 提取完成 │ 50概念 · 120关系                      │ ← 状态栏（独立）
├─────────────────────────────────────────────────────┤
│ (可滚动区域)                                        │
│ ...                                                 │

```

## ADDED Requirements

### Requirement: 固定顶部工具栏

系统 SHALL 在文献提取面板的**最顶部**提供一个**固定定位（sticky）**的工具栏。

#### 场景 1: 输入阶段显示

**WHEN** 用户处于输入阶段（未执行过提取或已重置）

**THEN** 工具栏 SHALL 显示以下按钮（从左到右）：

| 按钮 | 图标 | 功能 | 条件 |
|------|------|------|------|
| 📋 粘贴 | `ClipboardPaste` | 从系统剪贴板粘贴文本内容 | 始终 |
| ⚙️ 选项 | `Settings` | 展开/收起高级选项 | 始终 |
| ❌ 关闭 | `X` | 关闭面板 | `onClose` 存在时 |

#### 场景 2: 结果阶段显示

**WHEN** 用户已完成提取（`extractedResult` 不为空）

**THEN** 工具栏 SHALL 显示以下按钮（从左到右）：

| 分组 | 按钮 | 图标 | 功能 | 条件 |
|------|------|------|------|------|
| 视图 | 查看结果/收起 | `Layers` / `ChevronUp` | 切换输入/结果视图 | 始终 |
| 数据 | 重置 | `RotateCcw` | 清空所有数据，返回输入 | 始终 |
| 数据 | 导出 | `Download` | 导出概念和关系为 JSON | 始终 |
| 数据 | 复制 | `Copy` | 复制摘要到剪贴板 | 始终 |
| 操作 | 保存 | `CheckCircle2` | 保存到知识图谱 | 始终 |
| 系统 | 关闭 | `X` | 关闭面板 | `onClose` 存在时 |

#### 场景 3: 滚动固定

**WHEN** 面板内容超出可视区域并向下滚动

**THEN** 工具栏 SHALL 保持固定在顶部可见位置（`position: sticky; top: 0`）

**AND** 工具栏 SHOULD 有半透明背景 + 模糊效果以增强视觉层次

#### 场景 4: 响应式设计

**WHEN** 面板宽度 < 640px（移动端）

**THEN** 所有按钮仅显示图标，隐藏文字标签

**AND** 按钮间距适当缩小

### Requirement: 导出功能

系统 SHALL 允许用户将提取结果导出为文件。

**WHEN** 用户点击"导出"按钮

**THEN** 系统 SHALL 生成一个包含以下内容的 JSON 文件：

```json
{
  "metadata": { "title": "...", "authors": [...], "year": "..." },
  "concepts": [
    { "title": "...", "type": "...", "description": "...", "similarity": 0.92 }
  ],
  "relations": [
    { "source": "...", "target": "...", "type": "...", "confidence": 0.87 }
  ],
  "extractedAt": "2025-01-15T14:30:00Z"
}
```

**AND** 自动触发浏览器下载

### Requirement: 复制功能

系统 SHALL 允许用户将提取结果的摘要复制到剪贴板。

**WHEN** 用户点击"复制"按钮

**THEN** 系统 SHALL 将以下格式的文本复制到剪贴板：

```
文献提取结果
━━━━━━━━━━━━━━━━━━━━━━
来源: MGGPT: A Multi-Graph GPT...
作者: Zhang et al. (2025)

概念 (50个):
• 知识图谱构建方法 (概念) - 92%
• GPT-4 大语言模型 (方法) - 87%
...

关系 (120条):
• 知识图谱 → GPT (关联) - 92%
...
```

**AND** 显示短暂的"已复制"成功提示

### Requirement: 粘贴功能

系统 SHALL 支持从剪贴板快速粘贴内容。

**WHEN** 用户点击"粘贴"按钮

**THEN** 系统 SHALL 尝试读取系统剪贴板的文本内容

**AND** 如果是文本模式，自动填充到文本输入框

**AND** 如果读取失败（权限问题），显示错误提示

## MODIFIED Requirements

### Requirement: 状态栏分离（之前已实现）

状态栏 SHALL 与工具栏完全分离，作为独立的第二行显示。

**WHEN** 显示提取完成状态

**THEN** 状态栏位于工具栏下方，仅显示统计信息（不含操作按钮）

## Implementation Notes

1. **Sticky 定位实现**：
   ```tsx
   <div className="sticky top-0 z-10 bg-white/80 dark:bg-slate-800/80 backdrop-blur-sm border-b">
     {/* 工具栏内容 */}
   </div>
   ```

2. **条件渲染逻辑**：
   ```tsx
   {extractedResult ? renderResultToolbar() : renderInputToolbar()}
   ```

3. **按钮分组**：使用 `<div className="w-px h-5 bg-gray-200" />` 作为分隔符

4. **导出实现**：使用 `Blob` + `URL.createObjectURL` + `<a>` 标签下载

5. **复制实现**：使用 `navigator.clipboard.writeText()` API
